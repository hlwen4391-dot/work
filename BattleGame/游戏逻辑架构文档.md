## 🎯 游戏流程

### 完整场景流程

```
MainMenuScene (主菜单)
    ↓ [点击"开始游戏"]
SelectScene (选择场景)
    ↓ [选择英雄和怪物] → 保存到 window.SelectedUnits
    ↓ [点击"开始战斗"]
BattleScene (战斗场景)
    ↓ [战斗进行中]
    ↓ [一方全部死亡]
GameOverScene (游戏结束场景)
    ↓ [点击"重新开始"] → 回到 SelectScene
    ↓ [点击"返回主菜单"] → 回到 MainMenuScene
    ↓ [点击"回放"] → 回到 BattleScene (自动回放)
```

### 详细流程说明

#### 1. MainMenuScene → SelectScene
- **触发**: 点击"开始游戏"按钮
- **代码**: `MainMenuScene.onStartClick()`
- **跳转**: `cc.director.loadScene("SelectScene")`

#### 2. SelectScene → BattleScene
- **触发**: 点击"开始战斗"按钮
- **前置条件**: 至少选择一个英雄或怪物
- **数据保存**: 
  ```javascript
  window.SelectedUnits = {
      heros: [...],      // 选中的英雄列表
      monsters: [...]    // 选中的怪物列表
  }
  ```
- **代码**: `SelectScene.onStartBattleClick()`
- **跳转**: `cc.director.loadScene("BattleScene")`

#### 3. BattleScene 战斗流程
- **初始化**: `BattleController.onLoad()`
  - 检测 `window.SelectedUnits`，如果存在则自动创建单位
  - 创建 `BattleSystem`、`BattleRecorder`（如果启用）
  - 初始化所有单位的组件（StatsComponent、TeamComponent、SkillComponent等）
- **战斗循环**: `BattleController.update(dt)` → `BattleSystem.update(dt)`
  - 按速度排序单位
  - 每个单位执行行动（ActionSystem.performAction）
  - 检查战斗是否结束
- **战斗结束**: `BattleController._onGameOver()`
  - 保存战斗记录到本地存储
  - 设置 `window.BattleGameResult`
  - 跳转到 `GameOverScene`

#### 4. GameOverScene 选项
- **重新开始**: 跳转到 `SelectScene`
- **返回主菜单**: 跳转到 `MainMenuScene`
- **回放**: 
  - 从战斗记录恢复 `window.SelectedUnits`
  - 跳转到 `BattleScene`
  - 自动开始回放

## 🏗️ 场景架构

### MainMenuScene (主菜单场景)
**文件**: `game/MainMenuScene.js`

**功能**:
- 显示主菜单UI
- 导航到选择场景

**关键属性**:
- `startButton`: 开始游戏按钮
- `selectSceneName`: 选择场景名称（默认"SelectScene"）

**关键方法**:
- `onStartClick()`: 跳转到选择场景

### SelectScene (选择场景)
**文件**: `game/SelectScene.js`

**功能**:
- 显示角色选择界面
- 管理选中状态
- 传递选中数据到战斗场景

**关键属性**:
- `selectSceneUI`: SelectSceneUI组件节点
- `backButton`: 返回主菜单按钮
- `startBattleButton`: 开始战斗按钮
- `menuSceneName`: 主菜单场景名称
- `battleSceneName`: 战斗场景名称

**关键方法**:
- `onBackClick()`: 返回主菜单
- `onStartBattleClick()`: 保存选中数据并跳转到战斗场景

**数据传递**:
```javascript
window.SelectedUnits = {
    heros: [
        {
            name: "战士",
            prefab: cc.Prefab,
            icon: cc.SpriteFrame,
            hp: 120,
            attack: 8,
            // ... 其他属性
        }
    ],
    monsters: [...]
}
```

### BattleScene (战斗场景)
**文件**: `game/BattleController.js`

**功能**:
- 初始化战斗系统
- 创建/管理战斗单位
- 驱动战斗循环
- 处理游戏结束

**关键属性**:
- `heroParent` / `monsterParent`: 单位父节点
- `heroArea*` / `monsterArea*`: 排兵布阵区域
- `unitScale`: 单位固定大小
- `enableRecording`: 是否启用战斗记录
- `gameOverSceneName`: 游戏结束场景名称
- `useSceneTransition`: 是否使用场景跳转

**关键方法**:
- `onLoad()`: 初始化战斗系统
- `update(dt)`: 每帧更新战斗系统
- `spawnUnitsFromSelection()`: 从选择场景数据创建单位
- `_createUnitNode()`: 创建单个单位节点
- `_calculateFormationPosition()`: 计算排兵布阵位置
- `_onGameOver()`: 处理游戏结束

**战斗循环**:
```javascript
update(dt) {
    if (!this.isReplaying) {
        this.battleSystem.update(dt);
    }
}
```

## ⚙️ 核心系统

### 1. BattleSystem (战斗系统)
**文件**: `system/BattleSystem.js`

**职责**:
- 管理战斗主循环
- 按速度排序单位
- 调用行动系统
- 检查战斗结束

**关键方法**:
- `update(deltaTime)`: 每帧更新
- `getSortedUnits()`: 按速度排序单位
- `isFinished()`: 检查战斗是否结束

**流程**:
```
update(dt)
    ↓
按速度排序所有单位
    ↓
for each 单位:
    ActionSystem.performAction()
    ↓
    检查战斗是否结束
```

---

### 2. ActionSystem (行动系统)
**文件**: `system/ActionSystem.js`

**职责**:
- 执行单位行动
- 更新Buff效果
- 选择目标
- 调用技能系统

**关键方法**:
- `performAction(entity, dt)`: 执行单位行动
- `pickRandomTarget(entity)`: 随机选择目标
- `updateBuffEffects(entity, dt)`: 更新Buff效果

**行动流程**:
```
performAction()
    ↓
1. 更新Buff效果
    ↓
2. 检查是否可以行动（眩晕等）
    ↓
3. 更新技能冷却
    ↓
4. 查找可用技能
    ↓
5. 随机选择目标
    ↓
6. 释放技能 (SkillSystem.useSkill)
    ↓
7. 检查目标死亡
```

---

### 3. SkillSystem (技能系统)
**文件**: `system/SkillSystem.js`

**职责**:
- 管理技能冷却
- 查找可用技能
- 释放技能
- 播放技能特效

**关键方法**:
- `findAvailableSkill(entity)`: 查找可用技能
- `useSkill(entity, target, skill, log, rand)`: 使用技能
- `_playSkillEffect(entity, target, skill)`: 播放技能特效

**技能配置**: `system/SkillConfig.js`
- 普通攻击
- 盾击（眩晕）
- 火球术（真实伤害+燃烧）
- 狂暴（攻击+速度）
- 兽化狂暴（持续伤害）
- 战吼（群体攻击+速度）
- 群体护盾

---

### 4. BuffSystem (Buff系统)
**文件**: `system/BuffSystem.js`

**职责**:
- 管理Buff的添加/移除
- 更新Buff持续时间
- 执行Buff效果（持续伤害、属性修改等）

**关键方法**:
- `addBuff(target, buff, log, recorder)`: 添加Buff
- `update(entity, dt, log, recorder)`: 更新Buff效果
- `removeBuff(target, buffName, log)`: 移除Buff

**Buff类型**: `system/BuffRegistry.js`
- 燃烧（持续伤害）
- 眩晕（无法行动）
- 狂暴（攻击+速度）
- 护盾（伤害吸收）

---

### 5. CombatSystem (战斗计算系统)
**文件**: `system/CombatSystem.js`

**职责**:
- 计算伤害
- 处理暴击/闪避
- 应用伤害到目标

**关键方法**:
- `damage(attacker, target, value, log, recorder, rand)`: 计算普通伤害
- `damageTrue(attacker, target, value, log, recorder)`: 真实伤害（无视防御）

---

### 6. DeathSystem (死亡系统)
**文件**: `system/DeathSystem.js`

**职责**:
- 检查单位死亡
- 处理死亡动画
- 从队伍中移除死亡单位

**关键方法**:
- `checkAndHandleDeath(entity)`: 检查并处理死亡

---

### 7. BattleRecorder (战斗记录系统)
**文件**: `system/BattleRecorder.js`

**职责**:
- 记录战斗事件
- 保存战斗记录到本地存储
- 保存单位初始状态和位置

**关键方法**:
- `startRecording(heros, monsters)`: 开始记录
- `recordEvent(type, data)`: 记录事件
- `saveToLocalStorage(key)`: 保存到本地存储
- `loadFromLocalStorage(key)`: 从本地存储加载

**记录的事件类型**:
- `actionStart`: 行动开始
- `skillUse`: 技能释放
- `damage`: 伤害
- `buffApply`: Buff应用
- `buffRemove`: Buff移除
- `death`: 死亡
- `gameOver`: 游戏结束

**保存的数据**:
- `initialState`: 单位初始状态（包括位置）
- `selectedUnits`: 选中的单位数据（包括位置）
- `events`: 所有战斗事件

---

### 8. BattleReplayer (战斗回放系统)
**文件**: `system/BattleReplayer.js`

**职责**:
- 回放战斗记录
- 恢复单位状态
- 按时间顺序执行事件

**关键方法**:
- `startReplay(battleRecord, heros, monsters)`: 开始回放
- `_buildUnitMap(heros, monsters, initialState)`: 构建单位映射
- `_restoreInitialState(initialState)`: 恢复初始状态
- `_onSkillUse(data)`: 处理技能使用事件
- `_onDamage(data)`: 处理伤害事件
- `_onDeath(data)`: 处理死亡事件

## 📊 数据流

### 1. 选择场景 → 战斗场景
```
SelectScene
    ↓
window.SelectedUnits = {
    heros: [unitData1, unitData2, ...],
    monsters: [unitData3, unitData4, ...]
}
    ↓
BattleScene.onLoad()
    ↓
检测 window.SelectedUnits
    ↓
spawnUnitsFromSelection()
    ↓
为每个单位创建节点并设置位置
```

### 2. 战斗场景 → 游戏结束场景
```
BattleScene
    ↓
战斗结束
    ↓
window.BattleGameResult = {
    winner: "hero",
    winnerText: "英雄"
}
    ↓
window.LastBattleRecordKey = "battle_replay_xxx"
    ↓
GameOverScene.onLoad()
    ↓
读取 window.BattleGameResult
    ↓
显示胜利信息
```

### 3. 游戏结束场景 → 回放
```
GameOverScene
    ↓
点击"回放"按钮
    ↓
从战斗记录恢复 window.SelectedUnits
    ↓
window.AutoStartReplay = {
    recordKey: "battle_replay_xxx",
    enabled: true
}
    ↓
跳转到 BattleScene
    ↓
BattleController._checkAutoReplay()
    ↓
ReplayController.loadAndReplay()
    ↓
开始回放
```

## 🎯 关键功能

### 1. 自动排兵布阵

**位置**: `BattleController._calculateFormationPosition()`

**逻辑**:
- 英雄在左边区域随机位置
- 怪物在右边区域随机位置
- 区域通过 `heroArea*` 和 `monsterArea*` 属性定义

**公式**:
```javascript
x = areaLeft + Math.random() * (areaRight - areaLeft)
y = areaBottom + Math.random() * (areaTop - areaBottom)
```

---

### 2. 战斗记录和回放

**记录流程**:
1. 战斗开始时：`BattleRecorder.startRecording()`
   - 保存单位初始状态和位置
   - 保存 `selectedUnits` 数据
2. 战斗过程中：记录所有事件
3. 战斗结束时：保存到本地存储

**回放流程**:
1. 从本地存储加载战斗记录
2. 恢复 `window.SelectedUnits`（包括位置信息）
3. 重新创建单位节点（使用保存的位置）
4. 按时间顺序执行事件

---

### 3. 单位创建流程

**从选择场景创建**:
```
spawnUnitsFromSelection()
    ↓
forEach selectedUnits.heros/monsters
    ↓
_createUnitNode(unitData, team, index, totalCount)
    ↓
1. 实例化Prefab
2. 设置父节点
3. 计算位置（优先使用保存的位置，否则随机）
4. 设置大小和面向
5. 初始化组件
```

---

### 4. 战斗循环

```
BattleController.update(dt)
    ↓
BattleSystem.update(dt)
    ↓
按速度排序单位
    ↓
for each 单位:
    ActionSystem.performAction()
        ↓
        1. 更新Buff
        2. 检查是否可以行动
        3. 更新技能CD
        4. 查找可用技能
        5. 选择目标
        6. 释放技能
            ↓
            - 播放特效
            - 计算伤害
            - 应用Buff
        7. 检查死亡
    ↓
检查战斗是否结束
```

## 🚀 总结

这是一个完整的回合制战斗游戏系统，采用ECS架构，包含：

1. **4个主要场景**: MainMenu → SelectScene → BattleScene → GameOverScene
2. **8个核心系统**: BattleSystem, ActionSystem, SkillSystem, BuffSystem, CombatSystem, DeathSystem, BattleRecorder, BattleReplayer
3. **7个核心组件**: StatsComponent, TeamComponent, SkillComponent, BuffComponent, HealthBar, AttackMover, SkillEffectPlayer
4. **完整的数据流**: 通过全局对象在场景间传递数据
5. **战斗记录和回放**: 支持保存和回放战斗过程
6. **自动排兵布阵**: 根据区域配置自动放置单位

整个系统高度模块化，易于扩展和维护。
