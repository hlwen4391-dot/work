# 战斗回放功能使用指南

## 功能概述

战斗回放系统可以记录战斗过程中的所有关键事件，并在之后重新播放这些事件，实现战斗回放功能。

## 系统组成

### 1. BattleRecorder（战斗记录器）
- 记录战斗过程中的所有事件
- 保存初始状态
- 支持保存到本地存储

### 2. BattleReplayer（战斗回放器）
- 根据记录回放战斗过程
- 支持暂停/继续
- 支持速度控制（0.5x - 5.0x）
- 支持跳转到指定事件

### 3. ReplayController（回放控制器）
- UI组件，提供回放控制界面
- 播放/暂停/停止按钮
- 速度控制滑块
- 进度显示

## 使用方法

### 步骤1：启用战斗记录

在 `BattleController` 组件中：
1. 找到 `Enable Recording` 属性
2. 勾选启用（默认已启用）

### 步骤2：保存战斗记录

战斗结束后，可以通过代码保存记录：

```javascript
// 在BattleController中
if (this.battleRecorder) {
    // 保存到本地存储
    this.battleRecorder.saveToLocalStorage("battle_record_1");
}
```

### 步骤3：创建回放控制UI

1. 在场景中创建一个节点，命名为 `ReplayController`
2. 挂载 `ReplayController` 组件
3. 创建UI子节点：
   - `ReplayPanel`（回放控制面板）
   - `PlayPauseButton`（播放/暂停按钮）
   - `StopButton`（停止按钮）
   - `SpeedSlider`（速度控制滑块，可选）
   - `ProgressBar`（进度条，可选）

### 步骤4：开始回放

```javascript
// 获取回放控制器
const replayController = this.node.getComponent("ReplayController");

// 从本地存储加载记录并回放
replayController.loadAndReplay("battle_record_1", heros, monsters);

// 或者直接使用记录数据
const record = this.battleRecorder.getRecord();
replayController.startReplay(record, heros, monsters);
```

## 记录的事件类型

系统会记录以下事件：

1. **actionStart** - 行动开始
   - 记录单位开始执行行动

2. **skillUse** - 技能释放
   - 记录施法者、目标、技能信息

3. **damage** - 伤害事件
   - 记录伤害值、是否暴击、是否闪避、是否真实伤害
   - 记录目标当前血量

4. **buffApply** - Buff应用
   - 记录目标获得Buff

5. **buffRemove** - Buff移除
   - 记录目标失去Buff

6. **death** - 死亡事件
   - 记录单位死亡

7. **gameOver** - 游戏结束
   - 记录胜利方

## 回放控制API

### ReplayController 方法

- `startReplay(record, heros, monsters)` - 开始回放
- `loadAndReplay(key, heros, monsters)` - 从本地存储加载并回放
- `onPlayPauseClick()` - 播放/暂停切换
- `onStopClick()` - 停止回放
- `onSpeedChange()` - 速度改变

### BattleReplayer 方法

- `startReplay(record, heros, monsters, onComplete)` - 开始回放
- `stopReplay()` - 停止回放
- `togglePause()` - 暂停/继续
- `setPlaybackSpeed(speed)` - 设置回放速度（0.5-5.0倍）
- `jumpToEvent(index)` - 跳转到指定事件

## 注意事项

1. **单位ID匹配**：回放时使用单位名称作为ID进行匹配，确保单位名称唯一

2. **随机数问题**：回放时不会重新计算随机数（闪避、暴击等），而是使用记录的结果

3. **动画同步**：回放时可能需要手动触发动画，确保视觉效果同步

4. **状态恢复**：回放会恢复单位的初始状态，然后按时间顺序执行事件

5. **性能考虑**：大量事件的回放可能影响性能，建议限制记录的事件数量

## 扩展功能

### 添加自定义事件记录

```javascript
// 在需要记录的地方
if (this.recorder) {
    this.recorder.recordEvent("customEvent", {
        customData: "value"
    });
}
```

### 自定义回放处理

在 `BattleReplayer._executeEvent()` 中添加新的事件类型处理：

```javascript
case "customEvent":
    this._onCustomEvent(data);
    break;
```

## 示例代码

### 在BattleController中保存记录

```javascript
_onGameOver(winner, winnerText) {
    // ... 其他代码 ...

    // 保存战斗记录
    if (this.battleRecorder) {
        const recordKey = `battle_${Date.now()}`;
        this.battleRecorder.saveToLocalStorage(recordKey);
        cc.log(`[BattleController] 战斗记录已保存: ${recordKey}`);
    }
}
```

### 在UI中触发回放

```javascript
// 在某个按钮的点击事件中
onReplayButtonClick() {
    const replayController = this.node.getComponent("ReplayController");
    const battleController = cc.find("Canvas/BattleController").getComponent("BattleController");
    
    replayController.loadAndReplay(
        "battle_record_1",
        battleController.heros,
        battleController.monsters
    );
}
```

## 故障排查

### 问题：回放时单位不匹配
- 检查单位名称是否唯一
- 确保回放时使用的单位列表与记录时一致

### 问题：回放速度不正常
- 检查 `playbackSpeed` 设置
- 确保时间戳计算正确

### 问题：回放时动画不同步
- 检查是否在回放事件中触发了动画
- 可能需要手动调用动画播放函数
