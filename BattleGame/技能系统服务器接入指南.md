# 技能系统服务器接入指南

## 📋 概述

技能系统已成功接入服务器，支持本地存储、服务器存储和混合模式。每个角色的技能数据可以独立保存和加载。

## ✅ 已完成的功能

### 1. 技能数据适配器（SkillDataAdapter）

**文件：** `BattleGame/assets/Scripts/system/SkillDataAdapter.js`

**功能：**
- ✅ 支持本地存储（localStorage）
- ✅ 支持服务器存储（HTTP API）
- ✅ 支持混合模式（本地缓存 + 服务器同步）
- ✅ 自动重试机制
- ✅ 错误处理和降级

**使用方法：**
```javascript
const SkillDataAdapter = require("SkillDataAdapter");

// 设置存储模式
SkillDataAdapter.setStorageMode("hybrid"); // 'local' | 'server' | 'hybrid'

// 保存技能数据
await SkillDataAdapter.saveCharacterSkills(characterName, skills);

// 加载技能数据
const skills = await SkillDataAdapter.loadCharacterSkills(characterName);
```

### 2. 技能数据管理器（SkillDataManager）

**文件：** `BattleGame/assets/Scripts/system/SkillDataManager.js`

**功能：**
- ✅ 封装技能数据的保存和加载
- ✅ 从角色节点提取技能数据
- ✅ 自动处理Promise（服务器模式）

**使用方法：**
```javascript
const SkillDataManager = require("SkillDataManager");

// 保存角色技能
await SkillDataManager.saveCharacterSkills(characterName, skills);

// 加载角色技能
const skills = await SkillDataManager.loadCharacterSkills(characterName);

// 从节点保存技能
SkillDataManager.saveSkillsFromNode(characterNode);
```

## 🔧 配置说明

### 客户端配置

在 `MainMenuScene.js` 中，技能数据适配器会自动初始化：

```javascript
// 在 _initServerConfig() 方法中
const SkillDataAdapter = require("SkillDataAdapter");
SkillDataAdapter.setStorageMode("hybrid"); // 混合模式
```

### 服务器配置

服务器会自动：
- ✅ 加载技能数据文件（`data/skills.json`）
- ✅ 每30秒自动保存技能数据
- ✅ 程序关闭时保存技能数据
- ✅ 在 `/api/admin/data` 中显示技能数据
- ✅ 在 `/api/admin/reset` 中重置技能数据

## 📝 使用示例

### 保存角色技能

```javascript
const SkillDataManager = require("SkillDataManager");

// 从角色节点保存技能
const characterNode = ...; // 获取角色节点
SkillDataManager.saveSkillsFromNode(characterNode);

// 或直接保存技能数组
const skills = [
    {
        id: 1,
        name: "普通攻击",
        cooldown: 0.5,
        requireRage: 0,
        isUltimate: false
    }
];
await SkillDataManager.saveCharacterSkills("战士", skills);
```

### 加载角色技能

```javascript
const SkillDataManager = require("SkillDataManager");

// 加载技能数据
const skills = await SkillDataManager.loadCharacterSkills("战士");
console.log("技能列表:", skills);
```

### BattleController自动加载

`BattleController` 在初始化角色时会自动从服务器加载技能数据：

1. 尝试从服务器加载技能
2. 如果成功，将技能ID转换为完整的技能配置（从SkillConfig）
3. 如果失败，使用默认技能配置

## 🔍 调试

### 查看所有技能数据

访问：`http://localhost:3000/api/admin/data`

响应中包含 `skills` 字段，显示所有角色的技能数据。

### 重置技能数据

```bash
POST http://localhost:3000/api/admin/reset
```

这会清空所有技能数据。

## ⚠️ 注意事项

1. **技能配置：** 服务器只保存技能的ID和基本属性，不保存effect函数。加载时会从`SkillConfig`中获取完整的技能配置。

2. **技能ID：** 确保技能ID与`SkillConfig`中的ID一致，否则无法正确加载技能配置。

3. **混合模式：** 推荐使用混合模式，这样即使服务器不可用，也能使用本地缓存。

4. **数据同步：** 在混合模式下，保存时会先保存到本地，然后同步到服务器。如果服务器同步失败，本地数据仍然有效。
