# 等级系统使用指南

## 概述

等级系统为游戏添加了角色等级、经验值和属性成长机制。每个等级都会提升角色的各项属性，使角色随着战斗的进行变得越来越强大。

## 核心功能

### 1. 等级配置系统 (`LevelConfig.js`)

定义了等级相关的所有配置：
- **最大等级**: 100级
- **经验值计算公式**: `baseExp * (level - 1) ^ 1.5`
- **属性加成**: 每级增加一定百分比的属性值
  - 生命值: +5%/级
  - 攻击力: +3%/级
  - 防御力: +3%/级
  - 速度: +2%/级
  - 暴击率: +1%/级
  - 闪避率: +1%/级

### 2. 属性组件扩展 (`StatsComponent.js`)

新增属性：
- `level`: 当前等级（默认1）
- `exp`: 当前经验值（默认0）
- `baseHp/baseAttack/baseDefense/baseSpeed/baseCrit/baseMiss`: 基础属性值（1级时的值）

新增方法：
- `addExp(value)`: 增加经验值，自动处理升级
- `updateExpBar()`: 更新经验条显示
- `isMaxLevel()`: 检查是否达到最大等级

### 3. 经验条UI组件 (`ExpBar.js`)

用于显示角色的经验值和等级：
- 支持 `ProgressBar` 和 `Sprite` 两种显示方式
- 可显示等级标签和经验值文本（当前/需要）

### 4. 等级系统 (`LevelSystem.js`)

提供等级相关的核心功能：
- `addExp(characterNode, expValue)`: 给角色添加经验值
- `useExpItem(characterNode, expItem)`: 使用经验道具
- `getLevelInfo(characterNode)`: 获取角色的等级信息
- `initLevel(characterNode, level, exp)`: 初始化角色的等级和经验值

### 5. 等级UI面板 (`LevelUI.js`)

完整的等级UI面板组件：
- 显示当前等级和经验值
- 显示经验条进度
- 提供使用经验道具的入口
- 显示升级动画和属性变化提示
- 达到最大等级时显示提示

## 使用方法

### 1. 在角色Prefab中添加经验条

1. 在角色的UI节点下创建一个经验条节点（例如：`ExpBar`）
2. 添加 `ExpBar` 组件
3. 设置 `expProgress`（ProgressBar组件）或 `expFill`（Sprite组件）
4. （可选）添加 `levelLabel` 和 `expLabel` 显示等级和经验值文本

### 2. 初始化角色等级

角色初始化时会自动调用 `LevelSystem.initLevel()`，默认等级为1，经验值为0。

如果需要设置初始等级，可以在 `UnitDataConfig.js` 中为角色数据添加 `level` 和 `exp` 属性：

```javascript
{
    name: "战士",
    level: 5,  // 初始等级
    exp: 0,    // 初始经验值
    hp: 120,
    // ... 其他属性
}
```

### 3. 给角色添加经验值

#### 方式1: 战斗胜利后自动获得经验

战斗胜利后，存活的英雄会自动获得50点经验值（可在 `BattleController._onGameOver()` 中调整）。

#### 方式2: 使用经验道具

```javascript
const LevelSystem = require("LevelSystem");

// 使用经验道具
const expItem = {
    id: "exp_item_100",
    name: "经验药水",
    expValue: 100
};

LevelSystem.useExpItem(characterNode, expItem);
```

#### 方式3: 直接添加经验值

```javascript
const LevelSystem = require("LevelSystem");

// 给角色添加100点经验值
const result = LevelSystem.addExp(characterNode, 100);

if (result.leveledUp) {
    cc.log(`升级到 ${result.newLevel} 级！`);
    cc.log(`属性变化:`, result.statChanges);
}
```

### 4. 创建等级UI面板

1. 创建一个UI节点（例如：`LevelUIPanel`）
2. 添加 `LevelUI` 组件
3. 设置以下属性：
   - `characterNode`: 要显示等级的角色节点
   - `levelLabel`: 等级标签
   - `expBar`: 经验条节点（需要有ExpBar组件）
   - `expTextLabel`: 经验值文本标签
   - `useExpItemButton`: 使用经验道具按钮（可选）
   - `levelUpTipNode`: 升级提示节点（可选）
   - `maxLevelTipLabel`: 最大等级提示标签（可选）

4. 调用 `setCharacter(characterNode)` 设置要显示的角色

### 5. 获取角色等级信息

```javascript
const LevelSystem = require("LevelSystem");

const levelInfo = LevelSystem.getLevelInfo(characterNode);

console.log(`等级: ${levelInfo.level}`);
console.log(`经验值: ${levelInfo.exp}`);
console.log(`当前等级经验: ${levelInfo.expInCurrentLevel}/${levelInfo.expToNext}`);
console.log(`经验进度: ${levelInfo.progress * 100}%`);
console.log(`是否满级: ${levelInfo.isMaxLevel}`);
```

## 属性成长示例

假设一个1级角色的基础属性为：
- HP: 100
- 攻击: 10
- 防御: 5
- 速度: 10

当角色升级到10级时，属性会变为：
- HP: 100 * (1 + 0.05 * 9) = 145
- 攻击: 10 * (1 + 0.03 * 9) = 12.7 ≈ 12
- 防御: 5 * (1 + 0.03 * 9) = 6.35 ≈ 6
- 速度: 10 * (1 + 0.02 * 9) = 11.8 ≈ 11

## 注意事项

1. **基础属性保存**: 角色的基础属性值会在 `onLoad()` 时自动保存，确保等级加成计算正确。

2. **最大等级限制**: 角色达到最大等级（100级）后，无法继续获得经验值。

3. **经验值溢出**: 如果一次性添加大量经验值，系统会自动处理多级升级的情况。

4. **属性更新**: 升级后，角色的所有属性会自动更新，包括攻击间隔（基于速度）。

5. **生命值处理**: 升级时，如果当前生命值超过新的最大生命值，会自动调整为最大生命值。

## 扩展建议

1. **经验值来源多样化**: 
   - 击败敌人时获得经验值
   - 完成任务时获得经验值
   - 使用经验道具

2. **等级突破系统**: 
   - 达到特定等级时需要突破材料
   - 突破后可以继续升级

3. **等级奖励**: 
   - 达到特定等级时解锁新技能
   - 达到特定等级时解锁新功能

4. **经验值显示优化**: 
   - 添加经验值获得动画
   - 添加升级特效
   - 添加属性变化对比显示
