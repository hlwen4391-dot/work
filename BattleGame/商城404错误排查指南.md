# 商城404错误排查指南

## 问题现象

控制台显示404错误：
- `GET http://localhost:3000/api/coins 404 (Not Found)`
- `POST http://localhost:3000/api/shop/purchase 404 (Not Found)`

## 可能的原因

### 1. 服务器没有运行 ⭐ 最常见

**检查方法：**
1. 打开命令行（PowerShell 或 CMD）
2. 运行：`netstat -ano | findstr :3000`
3. 如果没有输出，说明服务器没有运行

**解决方法：**
1. 在 `BattleGame` 目录下运行：`node server.js`
2. 应该看到类似输出：
   ```
   ✅ 单个角色数据服务器运行在 http://localhost:3000
   API端点（端口3000）：
     GET  /api/coins                  - 获取金币数量
     POST /api/coins/add               - 增加金币
     POST /api/coins/spend            - 减少金币
     POST /api/shop/purchase          - 购买商品
   ```

### 2. 服务器端口被占用

**检查方法：**
运行：`netstat -ano | findstr :3000`

如果看到输出，说明端口被占用。

**解决方法：**
1. 找到占用端口的进程ID（PID）
2. 关闭该进程：`taskkill /PID <PID> /F`
3. 或者修改 `server.js` 中的 `PORT` 为其他端口（如3002）
4. 同时修改 `MainMenuScene.js` 中的服务器地址

### 3. URL路径问题（已修复）

**问题：**
之前代码中URL路径重复：`/api/api/coins`

**修复：**
已修复为正确的路径：
- `CoinManager.js`: `${ServerConfig.getBaseURL()}/coins` → `http://localhost:3000/api/coins` ✓
- `ShopUI.js`: `${ServerConfig.getBaseURL()}/shop/purchase` → `http://localhost:3000/api/shop/purchase` ✓

### 4. 身份验证问题

**检查：**
服务器端的 `authenticateToken` 中间件可能会拒绝请求。

**解决方法：**
检查 `MainMenuScene.js` 中的服务器配置：
```javascript
auth: {
    enabled: true,
    token: "1" // 用户ID（简化处理）
}
```

如果身份验证有问题，服务器会返回401而不是404。

## 快速排查步骤

1. **检查服务器是否运行**
   ```bash
   cd BattleGame
   node server.js
   ```

2. **检查控制台输出**
   - 服务器启动后应该显示所有API端点
   - 包括 `/api/coins` 和 `/api/shop/purchase`

3. **测试API端点**
   在浏览器中访问：`http://localhost:3000/api/coins`
   - 如果返回JSON数据，说明服务器正常
   - 如果404，说明路由没有注册

4. **检查客户端配置**
   确认 `MainMenuScene.js` 中的服务器地址：
   ```javascript
   baseURL: "http://localhost:3000/api"
   ```

## 常见错误

### 错误1：服务器没有运行
**症状：** 所有API请求都返回404
**解决：** 启动服务器 `node server.js`

### 错误2：端口被占用
**症状：** 服务器启动失败，提示端口被占用
**解决：** 关闭占用端口的进程或修改端口

### 错误3：URL路径错误
**症状：** 404错误，URL显示 `/api/api/coins`
**解决：** 已修复，确保使用 `${ServerConfig.getBaseURL()}/coins` 而不是 `${ServerConfig.getBaseURL()}/api/coins`

启动服务器后，应该看到：
```
========================================

数据目录: D:\work\BattleGame\data
角色数据文件: D:\work\BattleGame\data\characters.json

  PUT  /api/inventory               - 保存道具列表
```

如果看到这些输出，说明服务器正常运行，API端点已注册。

## 如果问题仍然存在

1. **检查服务器日志**
   - 查看服务器控制台是否有错误信息
   - 检查是否有路由注册失败的消息

2. **检查网络请求**
   - 在浏览器开发者工具的Network标签中查看请求详情
   - 确认请求URL是否正确
   - 查看响应状态码和错误信息

3. **检查代码版本**
   - 确认 `CoinManager.js` 和 `ShopUI.js` 使用的是修复后的代码
   - 确认 `server.js` 中已注册金币和商城API路由
