# 道具图标设置完整流程

## 概述

道具图标的设置流程分为以下几个步骤：
1. **在编辑器中绑定图标资源**（ItemIconSetter组件）
2. **图标资源赋值给ItemConfig**（运行时自动完成）
3. **获取道具数据时包含图标**（ItemDataManager）
4. **在UI中显示图标**（CharacterViewUI）

---

## 1. ItemIconSetter.js - 图标设置器

**文件位置：** `BattleGame/assets/Scripts/ecs/ItemIconSetter.js`

**作用：** 在编辑器中绑定图标资源，运行时自动设置到ItemConfig

```javascript
/**
 * 道具图标设置器
 * 在编辑器中绑定道具图标资源，运行时自动设置到ItemConfig
 */
cc.Class({
    extends: cc.Component,

    properties: {
        // 升级药水图标
        upgradePotionIcon: {
            default: null,
            type: cc.SpriteFrame,
            tooltip: "升级药水图标（SpriteFrame）"
        }
    },

    onLoad() {
        const ItemConfig = require("ItemConfig");

        // 设置升级药水图标
        const upgradePotion = ItemConfig.getItemById("upgrade_potion");
        if (upgradePotion && this.upgradePotionIcon) {
            upgradePotion.icon = this.upgradePotionIcon;  // ⭐ 关键：将SpriteFrame赋值给ItemConfig
            cc.log("[ItemIconSetter] ✓ 设置升级药水图标成功");
        } else if (upgradePotion && !this.upgradePotionIcon) {
            cc.warn("[ItemIconSetter] ⚠️ 升级药水图标未设置，请在编辑器中绑定");
        }
    }
});
```

**使用方法：**
1. 在场景中添加一个节点（例如Canvas下的某个节点）
2. 添加 `ItemIconSetter` 组件
3. 将升级药水图标的 `SpriteFrame` 资源拖拽到 `upgradePotionIcon` 属性
4. 运行时，`onLoad()` 会自动执行，将图标赋值给 `ItemConfig.items[0].icon`

## 2. ItemConfig.js - 道具配置

**文件位置：** `BattleGame/assets/Scripts/game/ItemConfig.js`

**作用：** 定义所有道具的基础数据，包括图标字段

```javascript
var ItemConfig = {
    // 所有道具配置列表
    items: [
        {
            id: "upgrade_potion",
            name: "升级药水",
            displayName: "升级药水",
            description: "使用后可以提升角色等级",
            icon: null, // ⭐ 图标资源（SpriteFrame，需要在编辑器中设置）
            type: "consumable",
            effectType: "level_up",
            effectValue: 1,
            maxStack: 99,
            rarity: "common",
            price: 100
        }
    ],

    /**
     * 根据ID获取道具配置
     */
    getItemById(itemId) {
        const item = this.items.find(item => item.id === itemId);
        return item || null;
    }
};
```

**关键点：**
- `icon` 字段初始为 `null`
- 运行时通过 `ItemIconSetter` 组件赋值
- 图标类型是 `cc.SpriteFrame`

## 3. ItemDataManager.js - 获取带图标的道具数据

**文件位置：** `BattleGame/assets/Scripts/system/ItemDataManager.js`

**作用：** 获取道具数据时，合并ItemConfig中的图标信息

```javascript
/**
 * 获取所有道具及其配置信息（包含图标）
 * @returns {Promise<Array>|Array} 道具列表 [{ itemId, count, config }, ...]
 */
getAllItemsWithConfig() {
    const ItemConfig = require("ItemConfig");
    const items = this.loadItems(); // 获取道具数据 [{ itemId, count }, ...]
    
    // 合并ItemConfig中的配置信息（包括图标）
    return items.map(item => {
        const config = ItemConfig.getItemById(item.itemId);
        return {
            itemId: item.itemId,
            count: item.count,
            config: config // ⭐ 包含icon字段的完整配置
        };
    });
}
```

**返回数据结构：**
```javascript
[
    {
        itemId: "upgrade_potion",
        count: 5,
        config: {
            id: "upgrade_potion",
            name: "升级药水",
            icon: SpriteFrame对象, // ⭐ 图标资源
            // ... 其他配置
        }
    }
]
```

## 4. CharacterViewUI.js - 在UI中显示图标

**文件位置：** `BattleGame/assets/Scripts/ecs/CharacterViewUI.js`

### 4.1 获取道具数据（包含图标）

```javascript
/**
 * 获取道具列表（全局共享，所有角色共用）
 */
async _getCharacterItems(characterName) {
    const ItemDataManager = require("ItemDataManager");

    // 获取全局道具（所有角色共享）
    const itemsWithConfig = await ItemDataManager.getAllItemsWithConfig();

    // 转换为显示格式
    return itemsWithConfig
        .filter(item => item.count > 0)
        .map(item => {
            return {
                id: item.itemId,
                name: item.config.displayName || item.config.name,
                icon: item.config.icon, // ⭐ 从config中提取icon
                count: item.count,
                config: item.config
            };
        });
}
```

### 4.2 设置道具格子图标

```javascript
/**
 * 设置道具格子内容
 */
_setItemSlot(slotNode, item) {
    // 查找图标节点
    const iconNode = slotNode.getChildByName("Icon") || slotNode;
    
    // 设置图标
    if (iconNode && item.icon) {
        const sprite = iconNode.getComponent(cc.Sprite);
        if (sprite) {
            sprite.spriteFrame = item.icon; // ⭐ 将SpriteFrame设置到Sprite组件
        }
        iconNode.opacity = 255; // 完全不透明
    }
}
```

## 检查清单

如果图标不显示，请检查：

1. ✅ **ItemIconSetter组件是否已添加**
   - 场景中是否有节点包含 `ItemIconSetter` 组件
   - `upgradePotionIcon` 属性是否已绑定SpriteFrame资源

2. ✅ **ItemConfig中icon是否已设置**
   - 查看控制台是否有 `[ItemIconSetter] ✓ 设置升级药水图标成功` 日志
   - 如果没有，检查ItemIconSetter组件是否正确绑定

3. ✅ **道具数据是否包含icon**
   - 查看控制台是否有 `[CharacterViewUI] 设置道具图标` 日志
   - 检查 `item.icon` 是否为有效的SpriteFrame对象

4. ✅ **Icon节点是否正确**
   - 道具格子Prefab中是否有名为 "Icon" 的子节点
   - Icon节点是否有 `cc.Sprite` 组件

5. ✅ **Icon节点是否可见**
   - `iconNode.opacity = 255`
   - `iconNode.active = true`
   - `iconNode.zIndex` 是否足够高（显示在背景之上）

## 添加新道具图标的步骤

如果要添加新道具的图标（例如经验药水）：

### 步骤1：在ItemIconSetter.js中添加属性

```javascript
properties: {
    upgradePotionIcon: { ... },
    
    // 添加经验药水图标
    expPotionIcon: {
        default: null,
        type: cc.SpriteFrame,
        tooltip: "经验药水图标（SpriteFrame）"
    }
}
```

### 步骤2：在onLoad中设置图标

```javascript
onLoad() {
    const ItemConfig = require("ItemConfig");
    
    // 设置升级药水图标
    const upgradePotion = ItemConfig.getItemById("upgrade_potion");
    if (upgradePotion && this.upgradePotionIcon) {
        upgradePotion.icon = this.upgradePotionIcon;
    }
    
    // 设置经验药水图标
    const expPotion = ItemConfig.getItemById("exp_potion");
    if (expPotion && this.expPotionIcon) {
        expPotion.icon = this.expPotionIcon;
        cc.log("[ItemIconSetter] ✓ 设置经验药水图标成功");
    }
}
```

### 步骤3：在编辑器中绑定

1. 选中包含ItemIconSetter组件的节点
2. 找到 `expPotionIcon` 属性
3. 将经验药水图标的SpriteFrame资源拖拽绑定

---

## 总结

道具图标的设置流程：
1. **编辑器绑定** → ItemIconSetter组件的属性绑定SpriteFrame
2. **运行时赋值** → ItemIconSetter.onLoad()将图标赋值给ItemConfig
3. **数据获取** → ItemDataManager合并ItemConfig配置（包含icon）
4. **UI显示** → CharacterViewUI将icon设置到Sprite组件的spriteFrame

**关键：** 图标必须在编辑器中通过ItemIconSetter组件绑定，运行时才能正确显示！
