# 道具弹窗问题排查指南

## 问题：节点都绑定了，但弹窗不显示

### 可能的原因和解决方案

---

## 1. 检查节点绑定

### ✅ 检查CharacterViewUI组件

1. 选中场景中的 `CharacterViewUI` 组件节点
2. 检查 `itemTooltip` 属性是否已绑定
3. 应该绑定到 `ItemTooltip` 节点

### ✅ 检查ItemTooltip组件

1. 选中 `ItemTooltip` 节点
2. 检查是否添加了 `ItemTooltip` 脚本组件
3. 检查所有子节点是否已绑定：
   - `nameLabel` - 道具名称标签
   - `descriptionLabel` - 描述标签
   - `effectLabel` - 效果标签
   - `countLabel` - 数量标签（可选）
   - `rarityLabel` - 稀有度标签（可选）
   - `typeLabel` - 类型标签（可选）

---

## 2. 检查节点层级和显示

### ✅ 节点层级

确保 `ItemTooltip` 节点在场景层级中：
- 应该在Canvas下，或者CharacterViewUI节点下
- **不要**放在其他可能遮挡的节点下

### ✅ 节点初始状态

1. 选中 `ItemTooltip` 节点
2. 检查 `active` 属性：
   - **应该设置为 `false`**（初始隐藏）
   - 代码会在需要时自动设置为 `true`

### ✅ 节点大小和位置

1. 检查 `ItemTooltip` 节点是否有内容大小
2. 如果使用背景图片，确保背景节点有大小
3. 如果使用Graphics绘制，确保绘制了内容

---

## 3. 检查控制台日志

运行游戏后，查看控制台输出：

### 正常情况应该看到：

```
[CharacterViewUI] 设置道具tooltip: upgrade_potion tooltip节点: ItemTooltip
[ItemTooltip] 显示道具信息: upgrade_potion 位置: ...
[ItemTooltip] 弹窗已显示，节点active: true 位置: ...
```

### 如果看到警告：

- `[CharacterViewUI] itemTooltip节点未绑定` → 需要在编辑器中绑定节点
- `[CharacterViewUI] itemTooltip节点没有ItemTooltip组件` → 需要添加ItemTooltip组件
- `[CharacterViewUI] 道具数据无效，缺少id字段` → 道具数据结构问题
- `[ItemTooltip] 道具数据无效` → 传入的数据格式不正确
- `[ItemTooltip] 未找到道具配置` → ItemConfig中没有该道具的配置

---

## 4. 检查事件触发

### ✅ 确保道具格子可以接收触摸事件

1. 检查道具格子节点：
   - 是否有 `cc.Button` 或其他可能拦截事件的组件
   - `_setItemSlot` 方法中设置了 `slotNode.setContentSize`

### ✅ 测试事件是否触发

在 `_setupItemTooltip` 方法中添加测试日志：

```javascript
slotNode.on(cc.Node.EventType.TOUCH_START, (event) => {
    cc.log("[测试] TOUCH_START事件触发");
    // ... 原有代码
}, this);
```

如果看不到这个日志，说明事件没有触发。

---

## 5. 检查位置计算

### ✅ 坐标转换问题

`event.getLocation()` 返回的是**屏幕坐标**（左下角为原点），需要正确转换：

1. 屏幕坐标 → 世界坐标
2. 世界坐标 → 节点本地坐标

代码已经处理了这个转换，但如果弹窗显示在错误位置，可能需要调整。

### ✅ 测试：固定位置显示

临时修改代码，使用固定位置测试：

```javascript
// 在_doShowItemInfo方法中，临时使用固定位置
this.node.setPosition(0, 0); // 屏幕中心
this.node.active = true;
```

如果固定位置可以显示，说明是位置计算问题。

---

## 6. 检查节点可见性

### ✅ Z-Index问题

确保弹窗显示在最上层：

1. 检查 `ItemTooltip` 节点的 `zIndex`
2. 代码中已设置 `this.node.zIndex = 1000`
3. 确保没有其他节点的zIndex更高

### ✅ 父节点遮挡

检查 `ItemTooltip` 的父节点：
- 是否有 `cc.Mask` 组件（可能裁剪子节点）
- 是否有 `opacity = 0`（可能隐藏子节点）
- 是否有 `active = false`（会隐藏所有子节点）

---

## 7. 常见问题解决

### ❌ 问题1：弹窗完全不显示

**检查：**
1. `ItemTooltip` 节点是否绑定
2. `ItemTooltip` 组件是否添加
3. 控制台是否有错误或警告

**解决：**
- 重新绑定节点
- 添加组件
- 检查控制台错误

### ❌ 问题2：弹窗显示但位置不对

**检查：**
1. 坐标转换是否正确
2. 父节点是否正确

**解决：**
- 检查位置计算代码
- 尝试固定位置测试

### ❌ 问题3：弹窗显示但内容为空

**检查：**
1. Label节点是否绑定
2. ItemConfig中是否有道具配置
3. 道具数据是否正确

**解决：**
- 绑定所有Label节点
- 检查ItemConfig配置
- 检查道具数据结构

### ❌ 问题4：鼠标悬停不触发

**检查：**
1. 道具格子节点是否可以接收触摸
2. 是否有其他组件拦截事件
3. 事件绑定是否正确

**解决：**
- 确保节点可以接收触摸
- 检查事件绑定代码
- 添加调试日志

### 步骤3：测试简化版本

创建一个简单的测试，直接显示弹窗：

```javascript
// 在CharacterViewUI的onLoad中添加测试按钮
this.scheduleOnce(() => {
    if (this.itemTooltip) {
        const tooltip = this.itemTooltip.getComponent("ItemTooltip");
        if (tooltip) {
            tooltip.showItemInfo({
                itemId: "upgrade_potion",
                count: 5
            }, new cc.Vec2(400, 300));
        }
    }
}, 2); // 2秒后显示
```

如果简化版本可以显示，说明是事件触发的问题。
