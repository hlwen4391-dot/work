# 获取所有角色数据使用指南

## 概述

现在服务器和客户端都支持获取所有角色数据的功能。你可以一次性获取当前用户的所有角色数据，而不需要逐个查询。

---

## 服务器API

### 获取所有角色数据

**接口：**
```
GET /api/characters
Headers:
  Authorization: Bearer {userId}  // 可选，默认使用用户ID=1
```


## 客户端使用

### 方法1：使用 CharacterDataManager（推荐）

```javascript
const CharacterDataManager = require("CharacterDataManager");

// 获取所有角色数据（支持异步）
const allCharacters = await CharacterDataManager.getAllCharacterData();

// 遍历所有角色
Object.keys(allCharacters).forEach(characterName => {
    const characterData = allCharacters[characterName];
    cc.log(`角色: ${characterName}, 等级: ${characterData.level}, 经验: ${characterData.exp}`);
});
```

### 方法2：直接使用 CharacterDataAdapter

```javascript
const CharacterDataAdapter = require("CharacterDataAdapter");

// 获取所有角色数据
const allCharacters = await CharacterDataAdapter.loadAllCharacterData();

// 使用数据
console.log("所有角色:", allCharacters);
```

## 完整示例

### 示例1：在游戏启动时加载所有角色数据

```javascript
// MainMenuScene.js 或游戏启动脚本
const CharacterDataManager = require("CharacterDataManager");

async onLoad() {
    // 初始化服务器配置
    this._initServerConfig();
    
    // 加载所有角色数据
    await this._loadAllCharacters();
}

async _loadAllCharacters() {
    try {
        const allCharacters = await CharacterDataManager.getAllCharacterData();
        
        cc.log(`[MainMenuScene] 已加载 ${Object.keys(allCharacters).length} 个角色的数据`);
        
        // 遍历所有角色
        Object.keys(allCharacters).forEach(characterName => {
            const data = allCharacters[characterName];
            cc.log(`[MainMenuScene] ${characterName}: 等级${data.level}, 经验${data.exp}`);
        });
        
        // 保存到全局变量供其他场景使用
        window.AllCharacters = allCharacters;
        
    } catch (error) {
        cc.error(`[MainMenuScene] 加载所有角色数据失败: ${error.message}`);
    }
}
```

## 存储模式说明

### 本地模式

```javascript
// 从localStorage获取所有数据
const allCharacters = CharacterDataManager.getAllCharacterData();
// 返回: { "战士": {...}, "法师": {...} }
```

### 服务器模式

```javascript
// 从服务器获取所有数据
const allCharacters = await CharacterDataManager.getAllCharacterData();
// 返回: { "战士": {...}, "法师": {...} }
```

### 混合模式（推荐）

```javascript
// 优先从服务器加载，失败则使用本地缓存
const allCharacters = await CharacterDataManager.getAllCharacterData();
// 返回: { "战士": {...}, "法师": {...} }
```

---

## 注意事项

1. **异步处理**：在服务器模式下，`getAllCharacterData()` 返回Promise，需要使用 `await` 或 `.then()`

2. **空数据**：如果没有角色数据，返回空对象 `{}`

3. **用户隔离**：数据按用户ID隔离，每个用户只能看到自己的角色数据

4. **性能考虑**：如果角色数量很多（100+），建议分批加载或使用分页

## 常见问题

### Q1: 如何判断是否有角色数据？

```javascript
const allCharacters = await CharacterDataManager.getAllCharacterData();
const hasCharacters = Object.keys(allCharacters).length > 0;

if (hasCharacters) {
    cc.log(`有 ${Object.keys(allCharacters).length} 个角色`);
} else {
    cc.log("没有角色数据");
}
```

### Q2: 如何获取特定角色的数据？

```javascript
const allCharacters = await CharacterDataManager.getAllCharacterData();
const warriorData = allCharacters["战士"];

if (warriorData) {
    cc.log(`战士等级: ${warriorData.level}`);
} else {
    cc.log("没有找到战士的数据");
}
```

### Q3: 如何遍历所有角色？

```javascript
const allCharacters = await CharacterDataManager.getAllCharacterData();

// 方法1: 使用 Object.keys()
Object.keys(allCharacters).forEach(characterName => {
    const data = allCharacters[characterName];
    cc.log(`${characterName}: 等级${data.level}`);
});

// 方法2: 使用 Object.entries()
Object.entries(allCharacters).forEach(([characterName, data]) => {
    cc.log(`${characterName}: 等级${data.level}`);
});

// 方法3: 使用 for...in
for (const characterName in allCharacters) {
    const data = allCharacters[characterName];
    cc.log(`${characterName}: 等级${data.level}`);
}
```
