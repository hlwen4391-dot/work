## 🎮 在编辑器中绑定粒子特效

### 步骤1：准备粒子特效Prefab

1. 在 Cocos Creator 中创建或导入你的粒子特效Prefab
2. 确保Prefab包含 `cc.ParticleSystem` 组件
3. 设置粒子系统的属性（颜色、大小、持续时间等）
4. 保存Prefab（例如：`HealParticle.prefab`）

### 步骤2：找到 SkillEffectPlayer 组件

1. 打开 `BattleScene` 场景
2. 在场景中找到 `SkillEffectPlayer` 节点（通常在Canvas下）
3. 如果不存在，需要创建一个：
   - 在Canvas下创建一个空节点，命名为 `SkillEffectPlayer`
   - 添加 `SkillEffectPlayer.js` 组件

### 步骤3：绑定粒子特效Prefab

1. 选中 `SkillEffectPlayer` 节点
2. 在属性检查器中找到 `SkillEffectPlayer` 组件
3. 找到 `Heal Particle Prefab` 属性
4. 将你的粒子特效Prefab拖拽到这个属性槽中

**完成！** 现在修女释放治疗术时会自动播放粒子特效。

## 🎨 粒子特效设置建议

### 推荐效果

治疗术特效应该体现"治疗"的感觉：

1. **颜色**：绿色系（如：RGB(50, 255, 50)）
2. **形状**：向上飘散的粒子（表示生命恢复）
3. **持续时间**：1-2秒
4. **位置**：在施法者身上（跟随施法者）

### 粒子系统设置示例

```
粒子类型：Gravity（重力模式）或 Radial（径向模式）
发射速度：50-100
粒子数量：20-50
生命周期：1-2秒
颜色：绿色渐变（从浅绿到透明）
大小：从小到大再变小
```

## 🔧 代码说明

### 特效播放逻辑

```javascript
// 1. 检查是否有粒子预制体
if (this.healParticlePrefab) {
    // 2. 实例化粒子特效
    const healParticle = cc.instantiate(this.healParticlePrefab);
    
    // 3. 添加到施法者节点上（跟随施法者）
    caster.addChild(healParticle);
    
    // 4. 启动粒子系统
    particleSystem.resetSystem();
    
    // 5. 延迟销毁（根据特效持续时间）
    // ...
} else {
    // 如果没有粒子预制体，使用绿色光环作为后备
    this._playHealEffectFallback(caster);
}
```

### 后备方案

如果没有绑定粒子特效Prefab，会自动使用绿色光环作为后备方案：
- 多个同心圆扩散效果
- 施法者轻微上浮动画
- 绿色系颜色

## 📝 特效属性说明

### `healParticlePrefab`
- **类型**：`cc.Prefab`
- **说明**：治疗术粒子特效预制体
- **位置**：`SkillEffectPlayer` 组件的属性面板
- **必需**：否（如果不绑定，会使用后备方案）

### `effectDuration`
- **类型**：`number`
- **默认值**：`1.0` 秒
- **说明**：特效持续时间（粒子特效会在此时长后销毁）

## ⚠️ 注意事项

1. **粒子系统组件**：确保粒子Prefab包含 `cc.ParticleSystem` 组件
2. **跟随模式**：粒子特效会自动跟随施法者（使用 `PositionType.RELATIVE`）
3. **自动销毁**：粒子特效会在 `effectDuration` 时间后自动销毁
4. **性能考虑**：如果粒子数量过多，可能影响性能，建议控制在50个以内

---

## 🔍 调试

如果特效没有显示，检查以下几点：

1. **Prefab是否正确绑定**
   - 检查 `SkillEffectPlayer` 组件的 `Heal Particle Prefab` 属性
   - 确保Prefab路径正确

2. **粒子系统是否启用**
   - 检查粒子Prefab中的 `cc.ParticleSystem` 组件
   - 确保 `Auto Play On Load` 已启用（或代码中会调用 `resetSystem()`）

3. **节点层级**
   - 粒子特效会添加到施法者节点上
   - 确保施法者节点可见且有效

4. **控制台日志**
   - 查看控制台是否有错误信息
   - 查看是否有 `[SkillEffectPlayer]` 相关的日志
