# 人物属性查看场景设置指南

## 功能说明

这个场景用于查看所有人物（英雄和怪物）的属性信息，包括：
- 左侧显示所有人物头像列表
- 点击头像显示人物原型（中间区域）
- 点击人物原型显示属性面板（HP、攻击、防御等）
- 点击任意地方关闭属性面板

## 场景设置步骤

### 1. 创建新场景

1. 在 Cocos Creator 中创建新场景：`CharacterViewScene.fire`
2. 场景结构建议：
   ```
   Canvas
   ├── CharacterViewUI (挂载 CharacterViewUI 组件)
   │   ├── AvatarListContainer (左侧头像列表容器)
   │   ├── CharacterDisplayArea (中间人物原型显示区域)
   │   └── StatsPanel (属性面板，半透明背景)
   │       ├── Background (半透明背景 Sprite)
   │       ├── HPLabel (生命值标签)
   │       ├── AttackLabel (攻击力标签)
   │       ├── DefenseLabel (防御力标签)
   │       ├── SpeedLabel (速度标签)
   │       ├── CritLabel (暴击率标签)
   │       ├── MissLabel (闪避率标签)
   │       ├── LevelLabel (等级标签)
   │       └── ExpLabel (经验值标签)
   └── BackButton (返回按钮，可选)
   ```

### 2. 设置 CharacterViewScene 组件

1. 在 Canvas 节点上添加 `CharacterViewScene` 组件
2. 设置属性：
   - **characterViewUI**: 拖拽 `CharacterViewUI` 节点
   - **backButton**: 拖拽返回按钮节点（可选）
   - **backSceneName**: 设置返回场景名称（如 "MainMenu"）

### 3. 设置 CharacterViewUI 组件

在 `CharacterViewUI` 节点上添加 `CharacterViewUI` 组件，并设置以下属性：

#### 基础节点绑定
- **avatarListContainer**: 拖拽左侧头像列表容器节点
- **characterDisplayArea**: 拖拽中间人物原型显示区域节点
- **statsPanel**: 拖拽属性面板节点

#### Prefab 和资源
- **avatarPrefab**: 拖拽头像 Prefab（可以使用现有的 `AvatarPrefab`）
- **heroIcons**: 拖拽英雄头像资源列表（按顺序对应 `UnitDataConfig` 中的英雄）
- **monsterIcons**: 拖拽怪物头像资源列表（按顺序对应 `UnitDataConfig` 中的怪物）
- **heroPrefabs**: 拖拽英雄 Prefab 列表（按顺序对应 `UnitDataConfig` 中的英雄）
- **monsterPrefabs**: 拖拽怪物 Prefab 列表（按顺序对应 `UnitDataConfig` 中的怪物）

#### 属性标签绑定
在 `StatsPanel` 节点下创建标签节点，并绑定到 `CharacterViewUI` 组件：
- **hpLabel**: 生命值标签
- **attackLabel**: 攻击力标签
- **defenseLabel**: 防御力标签
- **speedLabel**: 速度标签
- **critLabel**: 暴击率标签
- **missLabel**: 闪避率标签
- **levelLabel**: 等级标签
- **expLabel**: 经验值标签

#### 其他设置
- **avatarSpacing**: 头像间距（默认 100）

### 4. 设置属性面板样式

1. 创建 `StatsPanel` 节点
2. 添加 `cc.Sprite` 组件作为背景
3. 设置背景颜色为半透明（如：RGBA(0, 0, 0, 200)）
4. 设置合适的大小（如：宽 300，高 400）
5. 添加所有属性标签作为子节点

### 5. 设置头像列表容器

1. 创建 `AvatarListContainer` 节点
2. 设置位置在左侧（如：X = -400）
3. 可以添加 `cc.Layout` 组件来管理头像排列（垂直布局）

### 6. 设置人物原型显示区域

1. 创建 `CharacterDisplayArea` 节点
2. 设置位置在中间（如：X = 0）
3. 设置合适的大小（如：宽 400，高 600）
4. 确保可以接收触摸事件

### 7. 添加返回按钮（可选）

1. 创建 `BackButton` 节点
2. 添加 `cc.Button` 组件
3. 绑定到 `CharacterViewScene` 的 `backButton` 属性

## 使用说明

### 场景跳转

从主菜单或其他场景跳转到人物属性查看场景：

```javascript
cc.director.loadScene("CharacterViewScene");
```

### 功能流程

1. **查看头像列表**：场景加载后，左侧自动显示所有人物头像
2. **选择人物**：点击左侧头像，中间区域显示对应的人物原型
3. **查看属性**：点击中间的人物原型，右侧弹出属性面板
4. **关闭面板**：点击任意地方（除属性面板和人物原型外），属性面板关闭

## 注意事项

1. **头像 Prefab**：确保头像 Prefab 包含 `Icon` 子节点（用于显示头像图片）
2. **人物 Prefab**：确保人物 Prefab 包含 `StatsComponent` 组件
3. **属性面板**：属性面板默认隐藏，点击人物原型时显示
4. **事件处理**：点击事件会自动处理，无需手动绑定
5. **等级数据**：人物属性会根据保存的等级数据自动计算和显示

## 属性面板显示内容

- **生命值**: 当前生命值 / 最大生命值
- **攻击力**: 当前攻击力（包含等级加成）
- **防御力**: 当前防御力（包含等级加成）
- **速度**: 当前速度（包含等级加成）
- **暴击率**: 当前暴击率（百分比）
- **闪避率**: 当前闪避率（百分比）
- **等级**: 当前等级
- **经验值**: 当前等级经验 / 升级所需经验

## 调试

如果遇到问题，可以查看控制台日志：
- `[CharacterViewScene]` - 场景相关日志
- `[CharacterViewUI]` - UI 组件相关日志

## 示例场景结构

```
Canvas
├── CharacterViewUI
│   ├── AvatarListContainer (左侧，X=-400)
│   │   └── (头像会动态创建在这里)
│   ├── CharacterDisplayArea (中间，X=0)
│   │   └── (人物原型会动态创建在这里)
│   └── StatsPanel (右侧，X=250，初始隐藏)
│       ├── Background (半透明背景)
│       ├── TitleLabel ("人物属性")
│       ├── HPLabel
│       ├── AttackLabel
│       ├── DefenseLabel
│       ├── SpeedLabel
│       ├── CritLabel
│       ├── MissLabel
│       ├── LevelLabel
│       └── ExpLabel
└── BackButton (右上角)
```

## 完成

设置完成后，运行场景即可使用人物属性查看功能！
