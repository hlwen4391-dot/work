# 客户端服务器配置说明

## 配置位置

服务器配置在 `MainMenuScene.js` 的 `_initServerConfig()` 方法中。

## 当前配置

```javascript
// 服务器地址
const serverBaseURL = "http://localhost:3000/api";

// 用户ID（简化处理，实际应该从登录系统获取）
const userId = "1";
```

## 如何修改配置

### 1. 修改服务器地址

如果服务器运行在不同的地址，修改 `serverBaseURL`：

```javascript
// 本地开发
const serverBaseURL = "http://localhost:3000/api";

// 局域网服务器
const serverBaseURL = "http://192.168.1.100:3000/api";

// 远程服务器
const serverBaseURL = "https://your-server.com/api";
```

### 2. 修改用户ID

如果有多用户系统，可以从登录系统获取用户ID：

```javascript
// 从登录系统获取用户ID
const userId = getUserToken(); // 或从其他地方获取

ServerConfig.init({
    baseURL: serverBaseURL,
    timeout: 5000,
    retryCount: 3,
    auth: {
        enabled: true,
        token: userId
    }
});
```

### 3. 修改存储模式

有三种存储模式可选：

#### 本地模式（默认，无需服务器）
```javascript
ItemDataAdapter.setStorageMode("local");
CharacterDataAdapter.setStorageMode("local");
```
- 数据保存在浏览器本地（localStorage）
- 不需要服务器
- 适合单机游戏

#### 服务器模式（需要服务器）
```javascript
ItemDataAdapter.setStorageMode("server");
CharacterDataAdapter.setStorageMode("server");
```
- 所有数据都保存在服务器
- 需要服务器运行
- 适合多设备同步

#### 混合模式（推荐）
```javascript
ItemDataAdapter.setStorageMode("hybrid");
CharacterDataAdapter.setStorageMode("hybrid");
```
- 优先从服务器加载，失败则使用本地缓存
- 保存时先保存到本地，然后同步到服务器
- 兼顾性能和可靠性
- **当前默认使用此模式**

## 配置说明

### 超时时间

```javascript
timeout: 5000  // 5秒超时
```

如果服务器响应慢，可以增加超时时间：

```javascript
timeout: 10000  // 10秒超时
```

### 重试次数

```javascript
retryCount: 3  // 失败后重试3次
```

如果网络不稳定，可以增加重试次数：

```javascript
retryCount: 5  // 失败后重试5次
```

## 测试配置

### 1. 检查服务器是否运行

在浏览器中访问：
```
http://localhost:3000/api/admin/data
```

如果能看到JSON数据，说明服务器正常运行。

### 2. 检查客户端连接

打开浏览器开发者工具（F12），查看：
- **Console标签**：查看是否有连接错误
- **Network标签**：查看API请求是否成功

### 3. 查看日志

在Cocos Creator控制台查看日志：
- `[MainMenuScene] ✓ 服务器配置已初始化` - 配置成功
- `[MainMenuScene] 服务器地址: http://localhost:3000/api` - 显示服务器地址
- `[MainMenuScene] 存储模式: 混合模式（本地+服务器）` - 显示存储模式

## 常见问题

### Q1: 服务器未运行怎么办？

**A:** 客户端会自动降级到本地模式，游戏仍然可以正常运行。数据会保存在浏览器本地。

### Q2: 如何切换到纯本地模式？

**A:** 修改 `MainMenuScene.js`：

```javascript
// 注释掉服务器配置，直接使用本地模式
// this._initServerConfig();

// 或者修改存储模式
ItemDataAdapter.setStorageMode("local");
CharacterDataAdapter.setStorageMode("local");
```

### Q3: 如何切换到纯服务器模式？

**A:** 修改 `MainMenuScene.js`：

```javascript
ItemDataAdapter.setStorageMode("server");
CharacterDataAdapter.setStorageMode("server");
```

**注意：** 纯服务器模式下，如果服务器未运行，游戏可能无法正常加载数据。

### Q4: 如何查看当前使用的存储模式？

**A:** 在Cocos Creator控制台查看日志，或者在浏览器控制台执行：

```javascript
// 查看道具系统存储模式
const ItemDataAdapter = require("ItemDataAdapter");
console.log("道具系统存储模式:", ItemDataAdapter.storageMode);

// 查看等级系统存储模式
const CharacterDataAdapter = require("CharacterDataAdapter");
console.log("等级系统存储模式:", CharacterDataAdapter.storageMode);
```

## 推荐配置

### 开发阶段
- 使用**本地模式**，无需启动服务器
- 快速开发和测试

### 测试阶段
- 使用**混合模式**，启动服务器
- 测试服务器同步功能

### 生产阶段
- 使用**混合模式**或**服务器模式**
- 确保服务器稳定运行

当前配置：

- ✅ 存储模式：混合模式（本地+服务器）
- ✅ 用户ID：`"1"`（简化处理）
