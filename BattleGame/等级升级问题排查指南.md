# 等级升级问题排查指南

## 为什么没有看到等级升级？

### 可能的原因

1. **经验值不够升级**
   - 从1级升到2级需要 **100点经验值**
   - 战斗胜利只给 **50点经验值**
   - 需要打 **2次战斗** 才能从1级升到2级

2. **经验条UI没有配置**
   - 角色Prefab上没有添加 `ExpBar` 组件
   - 经验条没有正确绑定

3. **战斗没有胜利**
   - 只有英雄胜利时才会获得经验值
   - 怪物胜利时不会获得经验值

4. **角色已死亡**
   - 只有存活的英雄才会获得经验值

## 如何检查

### 1. 查看控制台日志

运行游戏后，战斗胜利时应该看到以下日志：

```
[BattleController] ===== 战斗胜利，开始分配经验值 =====
[BattleController] 经验奖励: 50 点/人
[BattleController] 给 战士 添加 50 点经验值
[LevelSystem] 战士 当前等级: 1, 当前经验: 0, 添加经验: 50
[StatsComponent] 战士 经验值变化: 0 + 50 = 50
[StatsComponent] 战士 等级计算: 旧等级=1, 新等级=1, 是否升级=false
[StatsComponent] 战士 当前经验进度: 50/100 (50.0%)
[LevelSystem] 战士 添加经验后 - 等级: 1, 经验: 50, 是否升级: false
[LevelSystem] 战士 未升级，距离下一级还需要 50 经验值
```

如果看到这些日志，说明经验值正在增加，只是还不够升级。

### 2. 检查经验条UI

确保角色Prefab上有经验条：
- 检查是否有 `ExpBar` 节点
- 检查 `ExpBar` 组件是否正确配置
- 检查 `expProgress` 或 `expFill` 是否绑定

### 3. 手动测试升级

在浏览器控制台（F12）输入：

```javascript
// 获取角色节点
const heroNode = cc.find("Canvas/Heros/Hero"); // 根据实际路径调整

// 添加大量经验值测试升级
const LevelSystem = require("LevelSystem");
const result = LevelSystem.addExp(heroNode, 200);

console.log("升级结果:", result);
```

如果这样能升级，说明升级逻辑正常，只是经验值不够。

## 解决方案

### 方案1：增加经验奖励（快速测试）

修改 `BattleController.js` 第983行：

```javascript
const expReward = 200; // 改为200，一次战斗就能升级
```

### 方案2：降低升级所需经验值

修改 `LevelConfig.js`：

```javascript
BASE_EXP: 50,  // 从100改为50，降低升级难度
```

### 方案3：添加经验条UI

如果经验条没有显示，需要：
1. 在角色Prefab中添加 `ExpBar` 节点
2. 添加 `ExpBar` 组件
3. 配置 `expProgress` 或 `expFill`

### 方案4：添加升级提示UI

升级时显示明显的提示，让玩家知道升级了。

## 经验值计算公式

- **1级升2级**: 需要 100 点经验值
- **2级升3级**: 需要 141 点经验值（总共241点）
- **3级升4级**: 需要 173 点经验值（总共414点）

公式：`所需经验 = 100 * (等级-1) ^ 1.5`

## 快速测试升级

在浏览器控制台输入：

```javascript
// 清除所有数据，从1级开始
const CharacterDataManager = require("CharacterDataManager");
CharacterDataManager.clearAllCharacterData();

// 给角色添加足够升级的经验值
const LevelSystem = require("LevelSystem");
const heroNode = cc.find("Canvas/Heros/Hero");
LevelSystem.addExp(heroNode, 200); // 添加200点，应该能升到2级

// 查看角色等级信息
const levelInfo = LevelSystem.getLevelInfo(heroNode);
console.log("等级信息:", levelInfo);
```
