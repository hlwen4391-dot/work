# 调试等级升级问题

## 问题：没有看到输出信息

可能的原因：
1. **控制台没有打开** - 需要按F12打开浏览器控制台
2. **日志被过滤** - 检查控制台的日志级别设置
3. **战斗没有胜利** - 只有英雄胜利时才会获得经验值
4. **`_onGameOver`没有被调用** - 检查战斗结束逻辑

## 调试步骤

### 1. 确认控制台已打开

运行游戏后，按 **F12** 打开浏览器控制台（Developer Tools）

### 2. 检查日志级别

在控制台中：
- 确保 "Info" 级别的日志没有被过滤
- 查看是否有 "Warnings" 或 "Errors"

### 3. 检查战斗是否胜利

战斗结束时，应该看到：
```
[BattleSystem] 准备调用游戏结束回调
[BattleSystem] 调用游戏结束回调: winner=hero, winnerText=英雄
[BattleController] ===== onGameOver回调被调用 =====
[BattleController] ===== _onGameOver方法被调用 =====
[BattleController] 游戏结束：英雄胜利
```

如果没有看到这些日志，说明 `_onGameOver` 没有被调用。

### 4. 手动测试经验值添加

在浏览器控制台输入：

```javascript
// 检查是否有角色节点
const heroNode = cc.find("Canvas/Heros/Hero");
console.log("角色节点:", heroNode);

// 检查StatsComponent
const StatsComponent = require("StatsComponent");
const stats = heroNode.getComponent(StatsComponent);
console.log("StatsComponent:", stats);
console.log("当前等级:", stats ? stats.level : "无");
console.log("当前经验:", stats ? stats.exp : "无");

// 手动添加经验值
const LevelSystem = require("LevelSystem");
const result = LevelSystem.addExp(heroNode, 200);
console.log("添加经验值结果:", result);
```

### 5. 检查本地存储数据

```javascript
// 查看所有保存的角色数据
const CharacterDataManager = require("CharacterDataManager");
const allData = CharacterDataManager.getAllCharacterData();
console.log("所有角色数据:", allData);

// 查看特定角色的数据
const heroData = CharacterDataManager.loadCharacterLevel("战士");
console.log("战士的数据:", heroData);
```

### 6. 检查经验条UI

```javascript
// 检查经验条组件
const heroNode = cc.find("Canvas/Heros/Hero");
const stats = heroNode.getComponent("StatsComponent");
console.log("ExpBar组件:", stats.expBar);
console.log("经验条节点:", stats.expBar ? stats.expBar.node : "无");
```

## 常见问题

### Q1: 完全没有日志输出？

**检查：**
- 控制台是否打开（F12）
- 日志级别设置是否正确
- 游戏是否正常运行

### Q2: 看到"游戏结束"但没有经验值相关日志？

**可能原因：**
- `winner !== "hero"` - 怪物胜利了
- `this.heros` 数组为空
- 所有英雄都死亡了

**检查：**
```javascript
// 在_onGameOver方法中添加
console.log("winner:", winner);
console.log("heros数量:", this.heros.length);
```

### Q3: 看到经验值日志但没有升级？

**可能原因：**
- 经验值不够升级（需要100点从1级升2级）
- 经验条UI没有更新

**检查：**
- 查看日志中的经验值进度
- 检查经验条组件是否正确配置

## 快速测试

在浏览器控制台运行：

```javascript
// 1. 清除所有数据
const CharacterDataManager = require("CharacterDataManager");
CharacterDataManager.clearAllCharacterData();
console.log("已清除所有数据");

// 2. 重新加载场景（刷新页面）
location.reload();

// 3. 战斗胜利后，检查经验值
const heroNode = cc.find("Canvas/Heros/Hero");
const stats = heroNode.getComponent("StatsComponent");
console.log("等级:", stats.level, "经验:", stats.exp);

// 4. 手动添加经验值测试
const LevelSystem = require("LevelSystem");
LevelSystem.addExp(heroNode, 200);
console.log("添加后 - 等级:", stats.level, "经验:", stats.exp);
```

按照以上步骤检查，应该能找到问题所在！
