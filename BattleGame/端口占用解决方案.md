# 端口占用解决方案

## 当前情况

端口 3000 和 3001 都被进程 ID **50692** 占用，说明**服务器已经在运行**了！

## 解决方案

### 方案1：使用已运行的服务器（推荐）⭐

**如果服务器已经在运行，你不需要重新启动它！**

直接使用现有的服务器即可。404错误可能是其他原因导致的。

### 方案2：关闭旧进程，重新启动服务器

如果你想重新启动服务器，需要先关闭占用端口的进程：

#### Windows PowerShell/CMD：

```powershell
# 关闭占用端口3000和3001的进程（PID: 50692）
taskkill /PID 50692 /F
```

然后重新启动服务器：
```bash
node server.js
```

#### 或者手动关闭：

1. 打开任务管理器（`Ctrl + Shift + Esc`）
2. 切换到"详细信息"标签
3. 找到 PID 为 50692 的进程
4. 右键点击 → 结束任务

### 方案3：修改服务器端口（如果不想关闭旧进程）

如果不想关闭旧进程，可以修改服务器使用其他端口：

1. **修改 `server.js`**：
   ```javascript
   const PORT = process.env.PORT || 3002; // 改为3002或其他可用端口
   const PORT_ALL = process.env.PORT_ALL || 3003; // 改为3003或其他可用端口
   ```

2. **修改 `MainMenuScene.js`** 中的服务器地址：
   ```javascript
   const serverBaseURL = "http://localhost:3002/api"; // 改为新端口
   const serverBaseURLForAll = "http://localhost:3003/api"; // 改为新端口
   ```

## 验证服务器是否正常运行

### 方法1：浏览器测试

在浏览器中访问：
- `http://localhost:3000/api/coins` - 应该返回JSON数据
- `http://localhost:3000/api/admin/data` - 查看所有数据

如果返回JSON数据，说明服务器正常运行。

### 方法2：检查服务器日志

如果服务器正在运行，你应该能在运行 `node server.js` 的终端窗口中看到：
- 服务器启动信息
- API端点列表
- 请求日志

## 如果404错误仍然存在

如果服务器已经在运行，但客户端仍然出现404错误，可能的原因：

1. **URL路径问题**（已修复）
   - 确认 `CoinManager.js` 使用 `${ServerConfig.getBaseURL()}/coins`
   - 确认 `ShopUI.js` 使用 `${ServerConfig.getBaseURL()}/shop/purchase`

2. **服务器路由未注册**
   - 检查服务器控制台是否显示 `/api/coins` 和 `/api/shop/purchase` 端点
   - 如果没有，说明服务器代码版本较旧，需要更新

3. **身份验证问题**
   - 检查 `MainMenuScene.js` 中的身份验证配置
   - 确认 `auth.enabled = true` 和 `token` 已设置
