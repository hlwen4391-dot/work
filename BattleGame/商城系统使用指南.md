# 商城系统使用指南

## 概述

商城系统是一个完整的购买系统，支持：
- 展示商品列表
- 购买商品（扣金币->发物品）
- 金币增减（统一入口）
- 状态返回（剩余金币、背包刷新）

## 文件结构

### 客户端文件

1. **`assets/Scripts/game/ShopConfig.js`**
   - 商城配置，定义所有可购买的商品及其价格
   - 可以在这里添加新商品

2. **`assets/Scripts/system/CoinManager.js`**
   - 金币系统管理器，统一管理金币的增减
   - 支持本地存储和服务器存储

3. **`assets/Scripts/game/ShopScene.js`**
   - 商城场景脚本，管理场景初始化和跳转

4. **`assets/Scripts/ecs/ShopUI.js`**
   - 商城UI组件，负责展示商品列表、处理购买等

### 服务器文件

**`server.js`**
- 已添加金币和商城相关的API接口：
  - `GET /api/coins` - 获取金币数量
  - `POST /api/coins/add` - 增加金币
  - `POST /api/coins/spend` - 减少金币
  - `POST /api/shop/purchase` - 购买商品（服务器端统一处理）

## 功能说明

### 1. 展示商城商品列表

商品列表在 `ShopConfig.js` 中定义：

```javascript
{
    id: "upgrade_potion_1",
    name: "升级药水",
    price: 100,
    itemId: "upgrade_potion", // 购买后获得的道具ID
    count: 1, // 购买数量
    icon: null, // 图标（由ItemIconSetter设置）
    description: "使用后可以提升角色等级",
    category: "consumable" // 消耗品
}
```

### 2. 购买商品（扣金币->发物品）

购买流程：
1. 检查金币是否足够
2. 扣除金币（通过 `CoinManager.spendCoins()`）
3. 添加道具到背包（通过 `ItemDataManager.addItem()`）
4. 更新金币显示
5. 刷新背包（如果需要）

**服务器模式**：使用 `/api/shop/purchase` API，服务器会原子性地处理金币扣除和道具添加，避免数据不一致。

**本地模式**：分别调用 `CoinManager.spendCoins()` 和 `ItemDataManager.addItem()`。

### 3. 金币增减（统一入口）

所有金币操作都通过 `CoinManager`：

```javascript
// 获取金币
const coins = await CoinManager.getCoins();

// 增加金币
await CoinManager.addCoins(100);

// 减少金币（购买时使用）
await CoinManager.spendCoins(50);
```

### 4. 状态返回（剩余金币、背包刷新）

购买成功后：
- 自动更新金币显示（`updateCoinDisplay()`）
- 道具已添加到背包（通过 `ItemDataManager`）
- 如果需要刷新背包UI，可以在购买成功后调用相应的刷新方法

## 在Cocos Creator中设置

### 1. 创建商城场景

1. 在Cocos Creator中创建新场景 `ShopScene`
2. 添加Canvas节点
3. 在Canvas下创建以下节点结构：

```
Canvas
├── ShopUI (添加ShopUI组件)
│   ├── CoinLabel (Label组件，显示金币)
│   ├── ItemListContainer (Node，商品列表容器)
│   ├── BackButton (Button，返回按钮)
│   └── RefreshButton (Button，刷新按钮，可选)
```

### 2. 创建商品项Prefab

1. 创建一个商品项Prefab，包含：
   - `NameLabel` (Label) - 商品名称
   - `PriceLabel` (Label) - 价格
   - `DescriptionLabel` (Label) - 描述
   - `Icon` (Sprite) - 图标（可选）
   - `BuyButton` (Button) - 购买按钮

2. 将Prefab保存到项目中

### 3. 配置ShopUI组件

在ShopUI节点上添加 `ShopUI` 组件，并绑定：
- `itemListContainer` - 商品列表容器节点
- `shopItemPrefab` - 商品项Prefab
- `coinLabel` - 金币显示标签
- `backButton` - 返回按钮节点
- `refreshButton` - 刷新按钮节点（可选）

### 4. 配置ShopScene组件

在ShopScene场景的根节点上添加 `ShopScene` 组件，并绑定：
- `shopUI` - ShopUI节点（可选，会自动查找）

### 5. 添加跳转到商城的按钮

在 `CharacterViewScene` 或 `MainMenuScene` 中添加按钮，跳转到商城：

```javascript
onShopButtonClick() {
    cc.director.loadScene("ShopScene");
}
```

## 添加新商品

在 `ShopConfig.js` 的 `getAllItems()` 方法中添加新商品：

```javascript
{
    id: "new_item_1",
    name: "新商品",
    price: 200,
    itemId: "new_item", // 必须在ItemConfig中定义
    count: 1,
    icon: null, // 需要在ItemIconSetter中设置
    description: "新商品的描述",
    category: "consumable"
}
```

**注意**：
- `itemId` 必须在 `ItemConfig.js` 中定义
- 图标需要在 `ItemIconSetter` 组件中设置

## 服务器API说明

### GET /api/coins
获取当前金币数量

**响应**：
```json
{
    "success": true,
    "coins": 1000
}
```

### POST /api/coins/add
增加金币

**请求**：
```json
{
    "amount": 100
}
```

**响应**：
```json
{
    "success": true,
    "coins": 1100,
    "added": 100
}
```

### POST /api/coins/spend
减少金币

**请求**：
```json
{
    "amount": 50
}
```

**响应**：
```json
{
    "success": true,
    "coins": 950,
    "spent": 50
}
```

**错误响应（金币不足）**：
```json
{
    "success": false,
    "error": "insufficient_coins",
    "currentCoins": 50,
    "required": 100,
    "message": "金币不足"
}
```

### POST /api/shop/purchase
购买商品（服务器端统一处理）

**请求**：
```json
{
    "shopItemId": "upgrade_potion_1",
    "itemId": "upgrade_potion",
    "count": 1,
    "price": 100
}
```

**响应**：
```json
{
    "success": true,
    "coins": 900,
    "items": [
        { "itemId": "upgrade_potion", "count": 1 }
    ],
    "purchased": {
        "itemId": "upgrade_potion",
        "count": 1
    }
}
```

## 数据存储

### 本地模式
- 金币存储在 `cc.sys.localStorage` 中，键为 `"player_coins"`
- 道具数据通过 `ItemDataManager` 管理

### 服务器模式
- 金币存储在服务器的 `data/coins.json` 文件中
- 道具数据存储在服务器的 `data/inventory.json` 文件中
- 数据按用户ID (`userId`) 分组存储

## 注意事项

1. **金币初始化**：默认金币数量为1000，可以在 `CoinManager.DEFAULT_COINS` 中修改

2. **服务器模式**：确保服务器已启动，并且 `ServerConfig` 已正确配置

3. **购买失败处理**：如果购买失败（如金币不足），不会扣除金币，也不会添加道具

4. **数据同步**：在服务器模式下，购买操作是原子性的，确保数据一致性

5. **背包刷新**：购买成功后，道具会自动添加到背包。如果需要刷新背包UI，需要在相应的场景中监听道具变化或手动刷新

## 测试建议

1. **测试购买流程**：
   - 检查金币是否足够
   - 购买商品
   - 验证金币是否正确扣除
   - 验证道具是否正确添加到背包

2. **测试金币不足**：
   - 设置金币为0
   - 尝试购买商品
   - 验证是否显示错误提示

3. **测试服务器模式**：
   - 启动服务器
   - 切换到服务器模式
   - 测试购买功能
   - 检查服务器日志和数据文件

4. **测试数据持久化**：
   - 购买商品
   - 关闭游戏
   - 重新打开游戏
   - 验证金币和道具数据是否保存
