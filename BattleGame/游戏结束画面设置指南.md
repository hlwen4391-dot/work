# 游戏结束画面设置指南

## 问题修复

已修复以下问题：
1. ✅ 修复了战斗开始时误判游戏结束的问题
2. ✅ 修复了胜利方判断逻辑（现在正确检查存活单位）
3. ✅ 确保游戏结束画面不会自动消失，会一直显示直到用户操作
4. ✅ 添加了防重复显示机制

## GameOverPanel 应该挂在哪里？

### 推荐位置：场景根节点或 Canvas 下

**最佳位置：**
```
场景
└── Canvas（如果有）
    └── GameOverPanel（节点，挂载GameOverPanel组件）
        ├── PanelBg（背景，半透明黑色Sprite）
        │   ├── GameOverLabel（文本："游戏结束"）
        │   ├── WinnerLabel（文本："英雄胜利！"或"怪物胜利！"）
        │   ├── RestartButton（可选，重新开始按钮）
        │   └── MenuButton（可选，返回主菜单按钮）
```

**或者直接在场景根节点下：**
```
场景
└── GameOverPanel（节点，挂载GameOverPanel组件）
    └── ...（同上）
```

### 为什么要在场景根节点或Canvas下？

1. **层级最高**：确保游戏结束画面显示在所有战斗元素之上
2. **不受战斗逻辑影响**：不会被战斗系统的节点操作影响
3. **易于管理**：作为UI层，独立于游戏逻辑

## 详细设置步骤

### 步骤1：创建GameOverPanel节点

1. 在场景中创建一个新节点，命名为 `GameOverPanel`
2. 将节点放在 **Canvas 下**（如果有Canvas）或 **场景根节点下**
3. 设置节点的 `Z` 坐标为较大的值（如 1000），确保在最上层

### 步骤2：挂载GameOverPanel组件

1. 选中 `GameOverPanel` 节点
2. 点击 **添加组件** → 搜索 `GameOverPanel`
3. 添加 `GameOverPanel` 组件

### 步骤3：创建UI子节点

在 `GameOverPanel` 节点下创建以下子节点：

#### 3.1 创建背景节点（PanelBg）

1. 创建子节点，命名为 `PanelBg`
2. 添加 `cc.Sprite` 组件
3. 设置背景颜色为半透明黑色（如：R=0, G=0, B=0, A=180）
4. 设置尺寸覆盖整个屏幕（如：1920x1080）
5. 在 `GameOverPanel` 组件的 `Panel Bg` 属性中绑定此节点

#### 3.2 创建文本标签

**GameOverLabel（游戏结束文本）：**
1. 创建子节点，命名为 `GameOverLabel`
2. 添加 `cc.Label` 组件
3. 设置文本为 "游戏结束"
4. 设置字体大小、颜色等样式
5. 在 `GameOverPanel` 组件的 `Game Over Label` 属性中绑定此节点

**WinnerLabel（胜利方文本）：**
1. 创建子节点，命名为 `WinnerLabel`
2. 添加 `cc.Label` 组件
3. 设置文本为 "英雄胜利！"（或"怪物胜利！"）
4. 设置字体大小、颜色等样式
5. 在 `GameOverPanel` 组件的 `Winner Label` 属性中绑定此节点

#### 3.3 创建按钮（可选）

**RestartButton（重新开始按钮）：**
1. 创建子节点，命名为 `RestartButton`
2. 添加 `cc.Button` 组件
3. 设置按钮样式和文本
4. 在 `GameOverPanel` 组件的 `Restart Button` 属性中绑定此按钮

**MenuButton（返回主菜单按钮）：**
1. 创建子节点，命名为 `MenuButton`
2. 添加 `cc.Button` 组件
3. 设置按钮样式和文本
4. 在 `GameOverPanel` 组件的 `Menu Button` 属性中绑定此按钮

### 步骤4：在BattleController中绑定

1. 选中场景中的 `BattleController` 节点
2. 在属性检查器中找到 `Game Over Panel` 属性
3. 将 `GameOverPanel` 节点拖入该属性

## 节点层级示例

```
场景 (Scene)
├── Canvas
│   ├── 战斗相关节点...
│   └── GameOverPanel ← 挂载GameOverPanel组件
│       ├── PanelBg (Sprite，半透明黑色背景)
│       │   ├── GameOverLabel (Label: "游戏结束")
│       │   ├── WinnerLabel (Label: "英雄胜利！")
│       │   ├── RestartButton (Button: "重新开始")
│       │   └── MenuButton (Button: "返回主菜单")
│       └── ...
└── BattleController ← 挂载BattleController组件
    └── (在Game Over Panel属性中绑定GameOverPanel节点)
```

## 功能说明

### 自动显示
- 当一方阵营全部死亡时，自动显示游戏结束画面
- 画面会以淡入和缩放动画显示

### 持续显示
- 游戏结束画面会一直显示，**不会自动消失**
- 只有用户点击按钮（重新开始或返回主菜单）才会关闭

### 防重复显示
- 已添加防重复显示机制，确保画面只显示一次

## 常见问题

### Q: 为什么在战斗开始时就显示了？
A: 已修复。现在会正确检查存活单位数量，不会在战斗开始时误判。

### Q: 画面会自动消失吗？
A: 不会。画面会一直显示直到用户点击按钮。

### Q: 可以自定义样式吗？
A: 可以。在编辑器中修改 `PanelBg`、`GameOverLabel`、`WinnerLabel` 等节点的样式即可。

### Q: 必须要有按钮吗？
A: 不是必须的。按钮是可选的，但建议至少添加一个重新开始按钮。
