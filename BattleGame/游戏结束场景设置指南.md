# 游戏结束场景设置指南

## 功能概述

现在游戏结束画面可以显示在独立的场景中，而不是在当前战斗场景中显示。这样可以提供更好的用户体验和更清晰的场景分离。

## 实现方式

### 方式1：场景跳转（推荐）
- 游戏结束时跳转到独立的游戏结束场景
- 场景间通过全局对象传递数据

### 方式2：当前场景显示（备用）
- 在当前战斗场景中显示游戏结束面板
- 适合快速测试或简单场景

## 设置步骤

### 步骤1：创建游戏结束场景

1. 在 Cocos Creator 中创建新场景：
   - 文件 → 新建 → 场景
   - 命名为 `GameOverScene`（或你喜欢的名称）

2. 在场景中创建UI结构：
   ```
   GameOverScene
   └── Canvas
       └── GameOverPanel（节点，挂载GameOverPanel组件）
           ├── PanelBg（背景，半透明黑色Sprite）
           │   ├── GameOverLabel（文本："游戏结束"）
           │   ├── WinnerLabel（文本："英雄胜利！"或"怪物胜利！"）
           │   ├── RestartButton（可选，重新开始按钮）
           │   └── MenuButton（可选，返回主菜单按钮）
   ```

### 步骤2：设置GameOverScene场景

1. 在场景根节点（或Canvas节点）上挂载 `GameOverScene` 组件：
   - 选中场景根节点
   - 添加组件 → 搜索 `GameOverScene`
   - 添加 `GameOverScene` 组件

2. 在 `GameOverScene` 组件中绑定节点：
   - `Game Over Panel`：绑定 `GameOverPanel` 节点
   - `Menu Button`：（可选）绑定返回主菜单按钮
   - `Restart Button`：（可选）绑定重新开始按钮

3. 在 `GameOverPanel` 节点上挂载 `GameOverPanel` 组件：
   - 选中 `GameOverPanel` 节点
   - 添加组件 → 搜索 `GameOverPanel`
   - 绑定相关子节点（PanelBg、WinnerLabel等）

### 步骤3：配置BattleController

1. 在战斗场景中，选中 `BattleController` 节点

2. 在属性检查器中设置：
   - `Use Scene Transition`：勾选（启用场景跳转）
   - `Game Over Scene Name`：设置为 `GameOverScene`（你的游戏结束场景名称）
   - `Game Over Panel`：可以留空（如果使用场景跳转）

### 步骤4：配置场景名称

确保场景文件名称与 `Game Over Scene Name` 设置一致：
- 如果场景文件是 `GameOverScene.fire`，则设置为 `GameOverScene`
- 如果场景文件是 `GameOver.fire`，则设置为 `GameOver`

## 数据传递机制

### 方法1：全局对象（当前实现）

在 `BattleController` 中，游戏结果会保存到 `window.BattleGameResult`：

```javascript
window.BattleGameResult = {
    winner: "hero",      // 或 "monster"
    winnerText: "英雄"   // 或 "怪物"
};
```

在 `GameOverScene` 中读取：

```javascript
if (window.BattleGameResult) {
    const winner = window.BattleGameResult.winner;
    const winnerText = window.BattleGameResult.winnerText;
}
```

### 方法2：场景数据组件（可选）

你也可以在场景根节点上挂载 `GameOverSceneData` 组件，手动设置数据（主要用于测试）。

## 按钮功能配置

### 重新开始按钮

在 `GameOverScene.js` 的 `onRestartClick()` 方法中：

```javascript
onRestartClick() {
    const battleSceneName = "BattleScene"; // 修改为你的战斗场景名称
    cc.director.loadScene(battleSceneName);
}
```

### 返回主菜单按钮

在 `GameOverScene.js` 的 `onMenuClick()` 方法中：

```javascript
onMenuClick() {
    const menuSceneName = "MainMenu"; // 修改为你的主菜单场景名称
    cc.director.loadScene(menuSceneName);
}
```

## 场景结构示例

### 战斗场景（BattleScene）
```
BattleScene
├── Canvas
│   ├── 战斗相关节点...
│   └── BattleController（挂载BattleController组件）
│       └── Use Scene Transition: true
│       └── Game Over Scene Name: "GameOverScene"
└── ...
```

### 游戏结束场景（GameOverScene）
```
GameOverScene
├── Canvas
│   └── GameOverPanel（挂载GameOverPanel组件）
│       ├── PanelBg
│       │   ├── GameOverLabel
│       │   ├── WinnerLabel
│       │   ├── RestartButton
│       │   └── MenuButton
└── GameOverScene（挂载GameOverScene组件）
    └── Game Over Panel: 绑定GameOverPanel节点
```

## 切换显示方式

### 使用场景跳转（推荐）
在 `BattleController` 中：
- `Use Scene Transition` = `true`
- `Game Over Scene Name` = `"GameOverScene"`

### 使用当前场景面板
在 `BattleController` 中：
- `Use Scene Transition` = `false`
- `Game Over Panel` = 绑定游戏结束面板节点

## 注意事项

1. **场景名称匹配**：确保 `Game Over Scene Name` 与场景文件名一致（不包括 `.fire` 扩展名）

2. **场景必须存在**：确保游戏结束场景已创建并保存在项目中

3. **数据传递时机**：数据在场景跳转前设置，跳转后立即可用

4. **延迟跳转**：代码中设置了0.5秒延迟，确保战斗动画完成后再跳转

5. **清理数据**：如果需要，可以在场景加载后清理全局数据：
   ```javascript
   // 在GameOverScene的onLoad中
   if (window.BattleGameResult) {
       // 使用数据
       const winner = window.BattleGameResult.winner;
       // 清理（可选）
       // delete window.BattleGameResult;
   }
   ```

## 测试步骤

1. 运行战斗场景
2. 让一方阵营全部死亡
3. 应该看到延迟0.5秒后自动跳转到游戏结束场景
4. 游戏结束场景应该显示正确的胜利方信息
5. 点击重新开始按钮应该返回战斗场景
6. 点击返回主菜单按钮应该跳转到主菜单（如果已配置）

## 故障排查

### 问题：场景跳转失败
- 检查场景名称是否正确
- 检查场景文件是否存在
- 查看控制台错误信息

### 问题：胜利信息显示错误
- 检查 `window.BattleGameResult` 是否正确设置
- 在 `GameOverScene` 的 `onLoad` 中添加日志查看数据

### 问题：按钮不响应
- 检查按钮是否正确绑定
- 检查按钮的 `interactable` 属性是否为 `true`
- 检查按钮节点是否在可点击层级
