# 道具信息弹窗使用指南

## 概述

道具信息弹窗（ItemTooltip）是一个UI组件，当鼠标悬停在道具格子上时，会显示道具的详细信息。

---

## 功能特性

- ✅ **鼠标悬停显示**：鼠标移动到道具格子上时自动显示
- ✅ **延迟显示**：避免快速移动鼠标时频繁显示/隐藏
- ✅ **自动定位**：智能调整位置，避免超出屏幕边界
- ✅ **详细信息**：显示名称、描述、效果、数量、稀有度等

---

## 创建弹窗UI

### 步骤1：在Cocos Creator中创建弹窗节点

1. 在 `CharacterViewScene` 场景中创建一个新节点，命名为 `ItemTooltip`
2. 设置节点属性：
   - **位置**：任意位置（会动态调整）
   - **锚点**：(0.5, 0.5)
   - **初始状态**：`active = false`（隐藏）

### 步骤2：设计弹窗UI结构

推荐的节点结构：

```
ItemTooltip (节点)
├── Background (背景，Sprite组件)
│   └── 设置半透明背景色
├── NameLabel (道具名称，Label组件)
├── DescriptionLabel (描述，Label组件)
├── EffectLabel (效果，Label组件)
├── CountLabel (数量，Label组件，可选)
├── RarityLabel (稀有度，Label组件，可选)
└── TypeLabel (类型，Label组件，可选)
```

### 步骤3：添加ItemTooltip组件

1. 选中 `ItemTooltip` 节点
2. 添加组件：`ItemTooltip`（脚本组件）
3. 绑定子节点：
   - `background` → Background节点
   - `nameLabel` → NameLabel节点
   - `descriptionLabel` → DescriptionLabel节点
   - `effectLabel` → EffectLabel节点
   - `countLabel` → CountLabel节点（可选）
   - `rarityLabel` → RarityLabel节点（可选）
   - `typeLabel` → TypeLabel节点（可选）

### 步骤4：配置组件属性

在ItemTooltip组件中设置：
- `showDelay`: 300（延迟300毫秒显示）
- `hideDelay`: 100（延迟100毫秒隐藏）

---

## 在CharacterViewUI中集成

### 步骤1：绑定弹窗节点

在 `CharacterViewUI` 组件中：
1. 找到 `itemTooltip` 属性
2. 将 `ItemTooltip` 节点拖拽绑定

### 步骤2：代码已自动集成

代码已经自动处理了：
- ✅ 鼠标移动到道具格子时显示tooltip
- ✅ 鼠标离开时隐藏tooltip
- ✅ 空格子不会显示tooltip

## 显示的信息

弹窗会显示以下信息：

1. **道具名称**：从 `ItemConfig` 获取
2. **描述**：道具的描述文本
3. **效果**：根据效果类型显示
   - 升级：提升X级
   - 经验：获得X点经验值
   - 生命：恢复X点生命值
   - 攻击：增加X点攻击力
   - 防御：增加X点防御力
4. **数量**：当前拥有的数量（如果>1）
5. **稀有度**：普通/稀有/史诗/传说（可选）
6. **类型**：消耗品/装备/材料（可选）

---

## 自定义显示内容

如果需要自定义显示内容，可以修改 `ItemTooltip.js` 中的 `_doShowItemInfo` 方法。

例如，添加价格显示：

```javascript
// 在ItemTooltip.js中添加
priceLabel: {
    default: null,
    type: cc.Label,
    tooltip: "价格标签（可选）"
},

// 在_doShowItemInfo方法中添加
if (this.priceLabel && itemConfig.price) {
    this.priceLabel.string = `价格：${itemConfig.price} 金币`;
}
```

## 注意事项

1. **性能优化**：
   - 使用延迟显示避免频繁创建/销毁
   - 弹窗节点应该预先创建，而不是动态创建

2. **位置调整**：
   - 弹窗会自动调整位置，避免超出屏幕
   - 默认显示在鼠标右上方
   - 如果超出边界，会自动调整到左侧或下方

3. **事件处理**：
   - 空格子不会触发tooltip
   - 点击道具时tooltip会自动隐藏

4. **多实例**：
   - 如果场景中有多个道具栏，可以共享同一个tooltip节点
   - 或者为每个道具栏创建独立的tooltip节点

## 故障排除

### Q1: 弹窗不显示

**检查：**
1. `ItemTooltip` 节点是否已创建
2. `ItemTooltip` 组件是否已添加到节点
3. `CharacterViewUI` 中的 `itemTooltip` 属性是否已绑定
4. 道具数据是否有效（`item.itemId` 是否存在）

### Q2: 弹窗位置不对

**检查：**
1. 弹窗节点的锚点设置（建议0.5, 0.5）
2. 弹窗的父节点是否正确
3. 位置计算逻辑是否正确

### Q3: 弹窗显示延迟太长

**调整：**
- 修改 `ItemTooltip` 组件的 `showDelay` 属性
- 默认300毫秒，可以改为100-200毫秒

### Q4: 弹窗内容不完整

**检查：**
1. `ItemConfig` 中道具配置是否完整
2. 弹窗中的Label节点是否都已绑定
3. 道具数据是否包含所有必要字段
