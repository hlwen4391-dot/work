# 清除等级数据指南

## 方法1：浏览器控制台（最快最简单）

运行游戏后，按 **F12** 打开浏览器控制台，输入以下代码：

### 清除所有角色的等级数据
```javascript
const CharacterDataManager = require("CharacterDataManager");
CharacterDataManager.clearAllCharacterData();
console.log("已清除所有角色的等级数据！");
```

### 清除单个角色的等级数据
```javascript
const CharacterDataManager = require("CharacterDataManager");
CharacterDataManager.deleteCharacterData("战士");  // 替换为角色名称
console.log("已清除该角色的等级数据！");
```

### 重置单个角色的等级（立即生效）
```javascript
const LevelSystem = require("LevelSystem");
const heroNode = cc.find("Canvas/Heros/Hero");  // 根据实际路径调整
LevelSystem.resetLevel(heroNode);
console.log("已重置角色等级！");
```

## 方法2：在主菜单添加清除按钮

在主菜单场景中添加一个"清除数据"按钮，点击后清除所有等级数据。

### 步骤：
1. 在 `MainMenuScene` 中添加清除按钮属性
2. 绑定按钮点击事件
3. 调用清除方法

### 代码示例：

修改 `MainMenuScene.js`：

```javascript
properties: {
    // ... 其他属性
    
    // 清除数据按钮（可选，用于测试）
    clearDataButton: {
        default: null,
        type: cc.Button,
        tooltip: "清除所有等级数据按钮（测试用）"
    }
},

onLoad() {
    // ... 现有代码
    
    // 绑定清除数据按钮事件
    if (this.clearDataButton) {
        this.clearDataButton.node.on(cc.Node.EventType.TOUCH_END, this.onClearDataClick, this);
    }
},

onClearDataClick() {
    const CharacterDataManager = require("CharacterDataManager");
    CharacterDataManager.clearAllCharacterData();
    cc.log("[MainMenuScene] 已清除所有角色的等级数据");
    alert("已清除所有角色的等级数据！");
}
```

## 推荐使用方法

**开发/测试时**：使用方法1（浏览器控制台），最快最方便

**正式游戏**：使用方法2（在主菜单添加清除按钮），用户友好

---

## 清除后的效果

- 所有角色的等级重置为1级
- 所有角色的经验值重置为0
- 所有角色的属性重置为基础值（1级时的值）
- 下次进入游戏时，角色会从1级开始

---

## 注意事项

⚠️ **清除数据是不可逆的操作！**

清除后：
- 所有保存的等级数据会被删除
- 角色会回到初始状态（1级，0经验）
- 需要重新升级才能恢复等级

建议：
- 在清除前先确认
- 可以添加确认对话框
- 或者添加"备份数据"功能
