# 商城商品容器优化说明

## 📋 优化内容

本次优化主要针对商城商品展示，确保每个商品都有独立的容器，内容严格限制在容器内，并为后续扩展做好准备。

## ✅ 已完成的优化

### 1. 商品容器背景和边框

**功能：** 每个商品项都有独立的卡片容器，带有清晰的背景和边框

**实现位置：** `ShopUI.js` → `_setupItemCardBackground()`

**特点：**
- ✅ 白色/浅色背景，深色边框
- ✅ 圆角设计（8px圆角半径）
- ✅ 2px边框宽度
- ✅ 根据商品类型自动调整颜色（消耗品、装备、材料等）

**代码示例：**
```javascript
// 自动为每个商品项添加背景和边框
_setupItemCardBackground(itemNode, shopItem);
```

### 2. 内容严格限制在容器内

**功能：** 使用Mask组件确保所有内容（图标、文字、按钮）不会超出容器边界

**实现位置：** `ShopUI.js` → `_setupItemCardMask()`

**特点：**
- ✅ 使用 `cc.Mask` 组件
- ✅ 矩形遮罩，略小于容器（留出边框空间）
- ✅ 自动裁剪超出内容

**代码示例：**
```javascript
// 添加遮罩，确保内容不超出容器
_setupItemCardMask(itemNode);
```

### 3. 描述文字自动换行

**功能：** 商品描述文字自动换行，且严格限制在容器内

**实现位置：** `ShopUI.js` → `setupShopItem()` → 描述标签设置

**特点：**
- ✅ `enableWrapText = true` - 启用自动换行
- ✅ `overflow = RESIZE_HEIGHT` - 自动调整高度
- ✅ 左对齐，顶部对齐，更易阅读
- ✅ 宽度限制：`容器宽度 - 24px（左右各12px内边距）`
- ✅ 最大高度限制：50px（防止占用过多空间）

**代码示例：**
```javascript
label.enableWrapText = true; // 启用自动换行
label.overflow = cc.Label.Overflow.RESIZE_HEIGHT; // 自动调整高度
descriptionLabel.setContentSize(descWidth, maxDescHeight); // 限制尺寸
```

### 4. 商品布局优化

**功能：** 优化商品项内部布局，确保所有元素都在容器内

**实现位置：** `ShopUI.js` → `_layoutShopItemContent()`

**布局顺序（从上到下）：**
1. **图标** - 顶部，70x70px，居中
2. **名称** - 图标下方，26px高度，居中
3. **描述** - 名称下方，最大50px高度，左对齐，自动换行
4. **价格** - 描述下方，28px高度，居中，金色突出
5. **购买按钮** - 底部，38px高度，居中，蓝色背景

**特点：**
- ✅ 使用相对位置计算，确保内容不重叠
- ✅ 所有元素都有内边距保护（12px）
- ✅ 自动验证内容是否超出容器边界

### 5. 为后续扩展做准备

**功能：** 代码结构优化，支持多种商品类型（消耗品、装备、材料等）

**实现位置：** `ShopConfig.js` → 新增方法和常量

**新增功能：**

#### 5.1 商品类型常量
```javascript
ShopConfig.CATEGORY = {
    CONSUMABLE: "consumable",  // 消耗品（药水等）
    EQUIPMENT: "equipment",     // 装备（武器、防具等）
    MATERIAL: "material",       // 材料（用于合成等）
    SPECIAL: "special"          // 特殊商品
};
```

#### 5.2 根据类型获取样式
```javascript
// 为不同类型的商品设置不同的颜色样式
const style = ShopConfig.getCategoryStyle(shopItem.category);
// 返回：{ backgroundColor, borderColor, nameColor, priceColor, descColor }
```

#### 5.3 获取所有分类
```javascript
// 获取所有商品分类列表（用于分类显示）
const categories = ShopConfig.getAllCategories();
```

## 📐 容器尺寸配置

在 `ShopUI.js` 的 `properties` 中可以配置：

```javascript
shopItemWidth: 180,      // 商品项宽度（卡片宽度）
shopItemHeight: 240,      // 商品项高度（卡片高度）
shopItemSpacing: 15,     // 商品项之间的间距
shopColumns: 4,          // 商品列表列数（每行显示的商品数量）
shopPadding: 20,         // 商品列表容器的内边距
```

## 📝 使用说明

### 1. 添加新商品

在 `ShopConfig.js` 的 `getAllItems()` 方法中添加：

```javascript
{
    id: "your_item_id",
    name: "商品名称",
    price: 100,
    itemId: "item_id",
    count: 1,
    icon: null,
    description: "商品描述（会自动换行）",
    category: ShopConfig.CATEGORY.CONSUMABLE // 或 EQUIPMENT, MATERIAL, SPECIAL
}
```

### 2. 自定义商品类型样式

在 `ShopConfig.js` 的 `getCategoryStyle()` 方法中添加新类型的样式：

```javascript
[this.CATEGORY.YOUR_TYPE]: {
    backgroundColor: new cc.Color(255, 255, 255, 255),
    borderColor: new cc.Color(0, 0, 0, 255),
    nameColor: new cc.Color(0, 0, 0, 255),
    priceColor: new cc.Color(255, 0, 0, 255),
    descColor: new cc.Color(128, 128, 128, 255)
}
```

### 3. 调整容器尺寸

在 Cocos Creator 编辑器中：
1. 选择 `ShopUI` 组件
2. 修改 `shopItemWidth`、`shopItemHeight` 等属性
3. 运行游戏查看效果

## ⚠️ 注意事项

1. **描述文字长度：** 描述文字会自动换行，但建议控制在合理长度内，避免占用过多空间
2. **容器尺寸：** 如果商品内容过多，可能需要调整 `shopItemHeight` 或减少描述文字
3. **Mask组件：** Mask组件会略微影响性能，如果商品数量很多（>100），可以考虑优化
4. **商品类型：** 添加新商品时，务必指定正确的 `category`，否则会使用默认样式
