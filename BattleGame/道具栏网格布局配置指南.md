# 道具栏网格布局配置指南

## 概述

在 Cocos Creator 中配置网格布局有两种方式：
1. **使用 Layout 组件（推荐）**：自动排列，简单高效
2. **手动计算位置**：完全控制，但代码复杂

本文档介绍如何使用 Layout 组件配置道具栏网格。

## 方式一：使用 Layout 组件（推荐）

### 1. 在编辑器中配置 Layout 组件

#### 步骤 1：创建道具栏容器节点
1. 在场景中创建节点，命名为 `InventoryContainer`
2. 设置位置在人物原型下方（例如：Y = -200）

#### 步骤 2：添加 Layout 组件
1. 选中 `InventoryContainer` 节点
2. 在 **属性检查器** 中点击 **添加组件**
3. 选择 **UI** → **Layout**

#### 步骤 3：配置 Layout 属性
在 Layout 组件的属性面板中设置：

- **Type（布局类型）**：选择 `GRID`（网格）
- **Resize Mode（缩放模式）**：选择 `CONTAINER`（容器自适应内容）
- **Cell Size（格子大小）**：
  - Width: `80`（与 `itemSlotSize` 一致）
  - Height: `80`
- **Start Axis（起始轴方向）**：选择 `HORIZONTAL`（水平方向开始排列）
- **Spacing X（水平间距）**：`10`（与 `itemSlotSpacing` 一致）
- **Spacing Y（垂直间距）**：`10`
- **Padding（内边距）**：全部设为 `0`

### 2. 代码自动配置（已实现）

代码会在运行时自动检查并配置 Layout 组件：

```javascript
// 检查是否已有Layout组件
let layout = this.inventoryContainer.getComponent(cc.Layout);
if (!layout) {
    layout = this.inventoryContainer.addComponent(cc.Layout);
}

// 配置为网格布局
layout.type = cc.Layout.Type.GRID;
layout.resizeMode = cc.Layout.ResizeMode.CONTAINER;
layout.cellSize = cc.size(this.itemSlotSize, this.itemSlotSize);
layout.spacingX = this.itemSlotSpacing;
layout.spacingY = this.itemSlotSpacing;
layout.startAxis = cc.Layout.AxisDirection.HORIZONTAL;
```

### 3. Layout 组件属性说明

| 属性 | 说明 | 推荐值 |
|------|------|--------|
| **Type** | 布局类型 | `GRID`（网格） |
| **Resize Mode** | 缩放模式 | `CONTAINER`（容器自适应） |
| **Cell Size** | 每个格子的大小 | 与 `itemSlotSize` 一致（如 80x80） |
| **Start Axis** | 起始轴方向 | `HORIZONTAL`（水平优先） |
| **Spacing X** | 水平间距 | 与 `itemSlotSpacing` 一致（如 10） |
| **Spacing Y** | 垂直间距 | 与 `itemSlotSpacing` 一致（如 10） |
| **Padding** | 内边距 | 全部设为 0（或根据需要调整） |

### 4. Layout 组件的优势

✅ **自动排列**：无需手动计算位置  
✅ **自适应**：容器大小自动调整  
✅ **易于维护**：修改间距和大小只需调整属性  
✅ **性能优化**：Cocos Creator 内部优化了布局计算  

## 方式二：手动计算位置（当前代码已改为方式一）

如果不想使用 Layout 组件，可以手动计算每个格子的位置：

```javascript
// 计算起始位置（居中显示）
const totalWidth = (this.inventoryColumns * slotSize) + ((this.inventoryColumns - 1) * spacing);
const totalHeight = (this.inventoryRows * slotSize) + ((this.inventoryRows - 1) * spacing);
const startX = -totalWidth / 2 + slotSize / 2;
const startY = totalHeight / 2 - slotSize / 2;

// 为每个格子计算位置
for (let i = 0; i < totalSlots; i++) {
    const row = Math.floor(i / this.inventoryColumns);
    const col = i % this.inventoryColumns;
    
    const x = startX + col * (slotSize + spacing);
    const y = startY - row * (slotSize + spacing);
    slotNode.setPosition(x, y);
}
```

## 完整配置步骤

### 1. 在 CharacterViewScene 中设置

1. 创建 `InventoryContainer` 节点
2. 设置位置在 `CharacterDisplayArea` 下方
3. （可选）添加 Layout 组件并配置（代码会自动配置）

### 2. 创建道具格子 Prefab

1. 创建节点，命名为 `ItemSlot`
2. 添加子节点：
   - `Icon`（Sprite，显示道具图标）
   - `CountLabel`（Label，显示数量，位置在右下角）
3. 设置 `ItemSlot` 大小为 80x80
4. 保存为 Prefab

### 3. 在 CharacterViewUI 组件中绑定

- **inventoryContainer**：拖拽 `InventoryContainer` 节点
- **itemSlotPrefab**：拖拽 `ItemSlot` Prefab
- **inventoryColumns**：设置为 `5`（每行5个）
- **inventoryRows**：设置为 `3`（共3行）
- **itemSlotSize**：设置为 `80`（与Prefab大小一致）
- **itemSlotSpacing**：设置为 `10`（格子间距）

## 注意事项

1. **Layout 组件延迟更新**：Layout 组件在下一帧才会更新布局，代码中已调用 `layout.updateLayout()` 立即生效

2. **容器大小**：代码会自动设置容器大小，确保网格居中显示

3. **格子大小一致性**：确保 `itemSlotSize`、`cellSize` 和 Prefab 大小一致

4. **性能考虑**：Layout 组件在子节点变化时会自动重新计算，对于大量格子（如 100+）可能需要优化

## 常见问题

**Q: Layout 组件没有生效？**  
A: 确保调用了 `layout.updateLayout()` 或等待下一帧更新。

**Q: 网格不居中？**  
A: 检查容器的锚点设置，建议使用 (0.5, 0.5) 居中锚点。

**Q: 格子重叠？**  
A: 检查 `cellSize` 和 `spacing` 是否正确设置，确保 `cellSize` 大于 Prefab 的实际大小。

**Q: 如何动态改变网格大小？**  
A: 修改 `inventoryColumns` 和 `inventoryRows` 后，重新调用 `_initInventory()` 方法。
