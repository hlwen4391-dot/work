# 端口占用问题解决方案

## 错误说明

`Error: listen EADDRINUSE: address already in use :::3000`

**含义：** 端口3000已经被其他程序占用了，无法启动服务器。

---

## 解决方案

### 方法1：关闭占用端口的进程（推荐）

#### Windows系统

1. **查找占用端口的进程：**
   ```bash
   netstat -ano | findstr :3000
   ```
   会显示类似：
   ```
   TCP    0.0.0.0:3000    0.0.0.0:0    LISTENING    12345
   ```
   最后的数字（12345）就是进程ID（PID）

2. **关闭进程：**
   ```bash
   taskkill /PID 12345 /F
   ```
   或者使用任务管理器：
   - 按 `Ctrl + Shift + Esc` 打开任务管理器
   - 切换到"详细信息"标签
   - 找到PID为12345的进程
   - 右键 -> 结束任务

#### Mac/Linux系统

1. **查找占用端口的进程：**
   ```bash
   lsof -i :3000
   ```
   或
   ```bash
   netstat -anv | grep 3000
   ```

2. **关闭进程：**
   ```bash
   kill -9 <PID>
   ```

---

### 方法2：更换端口

如果不想关闭占用端口的程序，可以更换服务器端口。

#### 修改 server.js

```javascript
const PORT = process.env.PORT || 3001; // 改为3001或其他端口
```

#### 修改客户端配置

在 `MainMenuScene.js` 中修改服务器地址：

```javascript
const serverBaseURL = "http://localhost:3001/api"; // 改为对应的端口
```

---

### 方法3：添加错误处理（推荐）

在服务器启动时添加错误处理，自动处理端口占用问题。

---

## 快速解决命令

### Windows

```bash
# 查找并关闭占用3000端口的进程（一行命令）
for /f "tokens=5" %a in ('netstat -ano ^| findstr :3000') do taskkill /PID %a /F
```

### Mac/Linux

```bash
# 查找并关闭占用3000端口的进程
lsof -ti:3000 | xargs kill -9
```

---

## 预防措施

建议在服务器代码中添加错误处理，自动处理端口占用问题。
